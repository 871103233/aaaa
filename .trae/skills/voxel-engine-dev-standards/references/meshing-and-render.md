# 网格化与渲染

渲染后端定稿为 **SDL3_gpu**（后端为 Vulkan / Direct3D 12 / Metal，不含 OpenGL）。**必读本节全部规则。**

## 1. 面剔除与贪婪合并

- **面剔除（V0.1 必做）**：只生成"相邻是空气或透明方块"的可见面。
- **贪婪合并（V0.2 必做，不得推迟）**：合并**同材质、同朝向、且 4 个角的天空光 / 方块光 / AO 完全一致**的连续面为大四边形，面数再压 3~10 倍。推迟到 V0.5 会导致顶点格式与数据结构整体重写。

### 1.1 两条硬约束（V0.2 定稿时即须满足）

1. **作用域 = 单个 Section**。顶点位置用 `uint8`（0~16），**禁止跨 Section 合并**，否则位置溢出。
2. **合并判据必须预留 AO**。AO 是逐顶点量，V0.5 开启后等价条件须包含"4 角 AO 相同"。
   **因此 V0.2 就写判据为"材质 + 朝向 + 4 角光照/AO 一致"，AO 先恒为 0 占位**；V0.5 只填真实值，无需重写网格器。

## 2. 顶点格式（单顶点 8 字节）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 位置 | `uint8 × 3` | Section 内相对坐标（0~16） |
| 光照 | `uint8` | 高 4 位天空光 + 低 4 位方块光 |
| 纹理 UV | `uint8 × 2` | **格内 UV（0~1 归一化）**，非最终采样坐标 |
| 法线 / 朝向 | `uint8` | 面朝向 |
| 附加 | `quadSize` | 该四边形跨的格数，用于 UV 平铺 |

对比传统的 `float×3 + float×2 + float×3`（32 字节），带宽省 75%。

### 2.1 UV 平铺约定（必读，否则纹理会拉伸）

贪婪合并出的大四边形需**重复平铺**纹理（1×N 格），因此 UV 不能只存 0~1：

- Vertex Shader 输出 `uv * quadSize`；
- Fragment Shader 用 `fract()` 采样。

**此约定必须在 V0.2 写贪婪网格之前固定。**

## 3. 纹理与合批

- **优先用纹理数组（Texture Array）而非图集**：SDL3_gpu 用多层 `SDL_GPUTexture`。
  图集在 mipmap 下会**渗色**（相邻 tile 在低 mip 混色，远处出现杂色），靠 1~2 px padding 不能根治；纹理数组每层独立 mipmap，无此问题，Shader 内 `(uv, layer)` 采样更直观。
- 每区块可见面合并为一个顶点 / 索引缓冲；非透明一个 draw call，透明（水 / 玻璃）单独一个并**按距离排序**。

### 3.1 Draw Call 目标（按视距分档）

| 视距 | 区块总数 | 剔除后可见 | Draw Call 目标 |
| --- | --- | --- | --- |
| 16 | 1089 | ~300 | **≤700/帧** |
| 24 | 2401 | 600~800 | **≤1500/帧** |

"几百以内"在 16 区块以上视距下不成立（原版 MC 本身就是数千 draw call）。
**若确需压到几百**：用 **Multi-Draw Indirect + 4×4 区块区域合批**（SDL3_gpu 已提供 `SDL_DrawGPUIndexedPrimitivesIndirect`），列为 V0.5 之后备选，复杂度显著上升。

## 4. 分渲染通道

- **不透明通道**：主通道，区块网格。
- **裁剪通道（alpha cutout）**：树叶等，需 alpha 测试。
- **半透明通道**：水 / 玻璃，**按从远到近排序**，否则出现"水中看不到远处方块"。OIT 留到后期。

## 5. LOD 与剔除

| 距离 | 策略 |
| --- | --- |
| 0~8 区块 | 完整贪婪网格 |
| 8~16 区块 | 2×2×1 合并网格 |
| 16~32 区块 | 4×4×2 合并网格或高度图 Impostor |
| > 32 区块 | Impostor 贴图（可选） |

- **视锥体裁剪**：CPU 侧用区块 AABB 剔除，视野外不提交 draw call。
- **遮挡剔除**：V0.5 加入（硬件遮挡查询或软件分层），洞穴与大世界必需。
- **LOD 接缝**：相邻不同 LOD 之间需缝合策略（裙边 / 顶点吸附）；用**指数雾与天空色混合**掩盖 LOD 切换跳变。

## 6. SDL3_gpu 专属约束

- Shader 须**离线编译为 SPIR-V**：GLSL 源 + 自写 include 预处理，经 **SDL_shadercross**（或 glslc/dxc）产出 SPIR-V / DXIL / MSL。
- 渲染线程是**唯一**可调用图形 API 的线程；顶点数据由 Worker 产出"上传包"，渲染线程执行上传。
- 命令缓冲支持多线程录制，但须按正确顺序提交。
- 抽象粒度不足时（bindless texture、mesh shader、GPU-driven 管线）才考虑下沉到手写 Vulkan 后端（V1.0 之后）。

## 7. 性能与观测

- GPU 计时用 **Tracy 的 GPU zone**；draw call / overdraw 统计用 **RenderDoc**（Vulkan/D3D12 后端；Metal 需 Xcode Metal Debugger）。
- 排查**面剔除错误、纹理数组 UV、光照 bug** 时优先用 RenderDoc 截帧。
- 渲染相关改动**必须附 Tracy 对比数据**。
