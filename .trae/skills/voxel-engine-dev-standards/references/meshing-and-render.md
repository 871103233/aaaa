# 网格化与渲染

涉及地表网格化、可挖体积网格化、材质混合、光照与渲染通道时读本文件。
**渲染后端固定为 SDL3_gpu**（后端为 Vulkan / Direct3D 12 / Metal，不含 OpenGL）。
**红线条款见主文件第一节红线表**；本文件只写"怎么落地"。世界表示与尺寸口径见方案 §2 / §4 / §7 与 ADR 0004~0008。

## 1. 地表高度场网格与法线

- 地表由**高度场直接网格化为平滑曲面**（每列一个高度）；**禁止**生成方块外观。
- 网格化以**地表 tile（64×64 列）**为单位，一列一个网格顶点。
- **法线由高度场梯度计算**并写入顶点属性；**禁止**在片元阶段用面法线近似。
- 相邻 tile 边界**必须几何连续**：边界列的高度来自共享采样，**禁止**各块按本块数据自行外推。
- 顶点位置以**块内定点坐标**存储，**禁止**用 `float` 承担世界定位（红线 6）。
- 重网格粒度 = 单 tile；改动列的边界影响邻 tile 时，邻 tile 一并重算（见 `chunk-and-streaming.md` §7）。

### 1.1 LOD 与接缝（待定，禁止自选）

- 地表 LOD 方案与接缝策略**尚未收敛**，登记在 SKILL「待收敛项」表 **#4（开放）**。
- 收敛前**禁止**实现，也**禁止**写候选方案。

## 2. 可挖体积：Surface Nets

- 算法 = **Naive Surface Nets**，密度 = **`int8` 距离场**，块 = **32³ 体素（含 33³ 采样）**。一行摘要，理由与备选见 ADR 0007。
- 密度语义：`d < 0` 为实心、`d > 0` 为空、`0` 为表面。
- 网格化**作用域 = 单块**；**必须**读取邻块边界采样，**块边界必须共享采样值**，**禁止**各自独立生成（ADR 0004 硬约束 3）。
- 每个 cell **至多产生 1 个顶点**，位置由该 cell 内边交点平均得到（保证挖掘时表面连续不跳变）。
- **法线由密度场梯度计算**并写入顶点属性；**禁止**用三角形面法线。
- 顶点位置以**块内定点坐标**存储。
- 体积重网格粒度 = 单体积块；与改动块共享边界采样的邻块一并重算。
- **层间过渡**：体积与地表相接处由**体积接管该列高度**。相接列的地表网格与体积网格**必须在同一批更新中重建**，否则出现缝隙与穿模。
- 算法升级（例如需要锐利硬边）**必须**按 ADR 0007 的切换条件另开 ADR；**禁止**在实现里并行维护两套网格化路径。

## 3. 材质：多纹理权重混合（splat）

- 地表材质 = **多纹理权重混合**，权重由**高度与坡度**决定；参与混合的纹理与权重曲线来自**材质表**（TOML，见 ADR 0005）。
- 纹理采样**必须**使用**纹理数组**（SDL3_gpu 的多层 `SDL_GPUTexture`）：
  - **禁止**使用纹理图集 —— 图集在 mipmap 下相邻 tile 会渗色，靠 padding 不能根治；纹理数组每层独立 mipmap。
  - 纹理数组**必须**在 V0.1 直接使用，**禁止**先用图集过渡。
  - 数组内所有层尺寸**必须一致**。
- 层号分配**只追加，不复用、不重排**；`index = 0` 保留给"缺失纹理"调试占位。
- 权重**逐像素**在片元着色器重算（不写入顶点属性），过渡带用窄带 `smoothstep`；每层各自的 UV 尺度与层色内插值噪声。
  每层贴图参数（高度带 / 坡度带 / UV 尺度 / 层色）**必须**与材质表同源，经 `BuildMaterialUniform` 单入口投影（ADR 0009）。
- 每层的 albedo / normal / roughness / AO **必须**来自同一份材质表；四件套与宏观变化见 ADR 0010 P2。
- 物件层材质 = 模型自带材质，**不参与**地表 splat。
- 离线纹理打包工具放 `tools/`（创建时须在 `docs/file-index.md` 登记）。

## 4. 光照与色彩：HDR → 阴影 → PBR → 抗锯齿

- 实施顺序**固定为四步且不得跳步**（ADR 0010）：① HDR 离屏目标 + 曝光 + 色调映射 + sRGB 编码；② 方向光 + CSM 级联阴影 + 半球天空光 + 指数高度雾；③ PBR（GGX / Smith / Schlick）+ roughness / AO；④ MSAA 与多频细节法线。
- **禁止**在未接入 HDR 与色调映射的情况下先做阴影或 PBR：亮部截断会吃掉全部增益。
- 光照方向 / 强度 / 颜色、雾、曝光、MSAA 档位**必须**进配置文件；**禁止**在着色器里写死第二份。
- **全屏后处理通道的 UV 必须翻转 V**：SDL_gpu 的裁剪空间是"左下角 `(-1,-1)`、+Y **向上**"，而纹理坐标是"左上角 `(0,0)`、+Y **向下**"
  （`SDL_gpu.h` §Coordinate System；后端差异由 SDL 自动转换）。因此全屏 blit 必须写
  `uv = vec2(pos.x * 0.5 + 0.5, 0.5 - pos.y * 0.5)`；照直写 `pos * 0.5 + 0.5` 会让**整帧上下翻转**
  （且因叠加层在其后直写交换链，表现为"UI 正常、世界倒置"）。**禁止**在其它通道再做翻转补偿。
- **禁止**引入逐方块光照与光照 BFS：本方向下**不存在逐方块光照数据**（ADR 0008 §4）。
- **深度通道（阴影）**：SDL3_gpu **不允许** `fragment_shader == nullptr`（`SDL_CreateGPUGraphicsPipeline` 会断言），
  因此深度通道**必须**挂一个**空入口**的片元着色器（`num_color_targets = 0`），深度写入由光栅化完成。
- **阴影采样器用 `NEAREST`**：线性过滤会在两个表面之间插出非物理深度、使 PCF 比较失真；
  PCF 的平滑靠**手动的 3×3 邻域**获得，不靠采样器过滤。
- **阴影通道的"相机相对顶点"**：主通道顶点是相机相对坐标（红线 6），阴影通道复用同一批顶点缓冲，
  故光空间矩阵**必须**在渲染原点坐标系下构造（等价于世界空间矩阵右乘 `translate(-renderOrigin)`）；
  **禁止**在别处再做平移补偿。
- **禁止**把光照打进地表 / 体积顶点色后依赖重网格更新光照；光照变化**不得**触发地形重网格。

## 5. 渲染通道、相机与剔除

- **不透明通道**：主通道，提交地表与体积的不透明部分。
- **裁剪通道（alpha cutout）**：树叶等需 alpha 测试的物件。
- **半透明通道**：**必须按距离排序**后再提交；OIT 留到后期。
- 合批粒度 = **单元**（单 tile / 单体积块）；**禁止**为每个子元素单独建顶点缓冲、单独绑纹理（红线 3）。
- **第三人称相机**：跟随角色胶囊，**必须**具备避障（不穿地形）；相机朝向只在渲染侧插值。
- **视锥体裁剪**：CPU 侧按单元包围盒剔除，视野外不提交。
- **遮挡剔除**：方案**尚未收敛**，登记在 SKILL「待收敛项」表 **#6（开放）**；收敛前**禁止**实现，也**禁止**写候选方案。
- **坐标精度**：世界定位用整数与 `double`，上传 GPU 前做**相机相对偏移**转 `float`（红线 6）。

## 6. 双格式 Shader 管线与 SDL3_gpu 约束（ADR 0002，仍然有效）

- Shader **必须离线编译为双格式**：GLSL 源 + 自写 include 预处理，经 `glslc` 产出 **SPIR-V**，
  再由 **SDL_shadercross** 转为 **DXIL**，**两种都必须产出**（见 ADR 0002）。
  Vulkan 只接受 SPIR-V、D3D12 只接受 DXIL，喂错会在 `SDL_CreateGPUShader` 处断言失败；
  运行时按 `SDL_GetGPUShaderFormats()` 的返回值选择加载哪一种。
- 渲染线程是**唯一**可调用图形 API 的线程；顶点数据由 Worker 产出"上传包"，渲染线程执行上传。
- 命令缓冲支持多线程录制，但**必须**按正确顺序提交。
- 抽象粒度不足时（bindless texture、mesh shader、GPU-driven 管线）才考虑下沉到手写 Vulkan 后端（V1.0 之后）。

## 7. 性能与观测

- GPU 计时用 **Tracy 的 GPU zone**；draw call 与 overdraw 统计用 **RenderDoc**（Vulkan / D3D12 后端；Metal 后端改用 Xcode Metal Debugger）。
- 排查**地表裂缝、体积接缝、splat 渗色、阴影瑕疵**时优先用 RenderDoc 截帧。
- 渲染相关改动**必须附 Tracy 对比数据**。
- **Draw Call 与长视距内存只记录、不验收**（方案 §7.3，ADR 0008 §2）；报告**必须**写明「基线配置 / tile 视距 / 是否启用 LOD / 是否含可挖体积」四项。
