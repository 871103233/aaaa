# 可破坏元素：分类、材质坚固度与伤害结算

涉及**可破坏性 / 材质坚固度 / 伤害 / 固定器物及其破坏状态**时读本文件。
**红线条款见主文件第一节红线表**；世界表示内部规则见 `chunk-and-streaming.md` 与 `meshing-and-render.md`；输入与玩法设施见 `gameplay-v0.1.md`；配置加载口径见 `save-and-serialization.md` 与 [ADR 0005](../../../docs/adr/0005-config-parsing.md)。
**权威解释（为什么这么做、备选与切换条件）见 [ADR 0013](../../../docs/adr/0013-destructible-elements.md)**；本文件只写"调用侧必须遵守什么"。

## 1. 分类与归属（先判归属，再动手）

| 元素 | 几何可变性 | 状态 | 归属层（ADR 0004） | 破坏路径 |
| --- | --- | --- | --- | --- |
| **地形体量**（地表高度场 / 可挖体积） | **可变**（任意形状） | 无 | ① / ② | 伤害预算 → **逐格³ 挖除** |
| **固定器物**（雕塑 / 机关 / 建筑构件 / 阵法设施） | **不可变** | `Intact` / `Broken` | ③ 物件与建造 | 伤害达阈值 → **状态切换 + 外观替换** |

**硬约束**：

- **"无法改变外形" ≠ "无法被破坏"**：器物分 `destructible = false`（完全不可破坏）与 `destructible = true`（可破坏，但**几何不变**，只切状态）。**禁止**把两者实现成同一个分支。
- **器物绝不写进地形场**：它是层 ③ 的实体（EnTT + Jolt 碰撞体），**禁止**把它的状态或几何写进高度场 / 体积密度场（红线 1 的延伸）。
- 新增任何元素类型 ⇒ **先在 `docs/game-design.md` 的能力清单登记**（状态 `未开始`），再实现（主文件六.5 / 六.7）。
- 本文件不覆盖"可破坏建造物（预制碎块 + 接合）"—— 那需要**另一份 ADR**，未定前**禁止**自行实现。

## 2. 伤害结算（只适用于地形体量）

**单位**（三者都由配置提供，见 §4）：

| 量 | 单位 | 来源 |
| --- | --- | --- |
| `damage`（伤害） | 点 | 弹丸表 |
| `toughness`（坚固度） | 点 / 格³ | 材质表（逐材质） |
| `points_per_cubic_block`（换算系数） | 格³ / 点 | 全局破坏表（**手感锚点**） |

**结算规则（必须逐字实现）**：

```
体积预算 V = damage × points_per_cubic_block          （格³）
自爆心向外，按"距爆心距离升序"逐格³ 扣减该格材质的 toughness；
余额不足以破坏下一格 ⇒ 停止（该格保留）
```

- **必须逐格扣减**，不得退化为"先算半径再挖球" —— 后者的可观察缺陷是：混合材质处**不会**出现"软的先被挖掉、硬的留在原地"。
- **遍历次序必须确定性**：距爆心同距时按整数坐标的确定性顺序（红线 7）。**禁止**随机 / 哈希洗牌 / 依赖容器迭代顺序。
- **预算结算必须用整数点**（`int`），**禁止**浮点累加决定"还能不能挖下一格"——浮点误差会让结果随编译选项漂移。
- **不可破坏材质**（`toughness = 0`，或 `indestructible = true` 这个**显式开关**）：**永不挖除**，且**不参与预算扣减**；爆炸完全落在其中 ⇒ **无改动**是正确结果。
  - **T52（2026-09-28，项目所有者指定）**：**岩层就是用它**实现"完全无法击毁、无法挖洞"——
    同一开关同时覆盖两条破坏路径：地形挖洞（`CarveByDamage`）与**碎块补丁雕刻**（T50 的 `CarveCollapseUnitPatch`），
    含该材质的整体**不被"小碎片清除"**（T43 守卫）。
  - **不受影响的三件事**：密度 / 质量、碰撞体、**命中判定** —— 光球**仍会打在岩石上**（被挡住并引爆，
    只是挖不动），岩石**仍会因失去支撑而作为刚体倒塌**（倒塌不是"破坏"，见 [ADR 0015](../../../docs/adr/0015-structure-units-and-rigid-collapse.md) / [ADR 0018](../../../docs/adr/0018-structural-support-and-representation-preserving-destruction.md)）。
  - 区域外**地表**只有高度场、无法逐列区分岩 / 土 ⇒ 采**整片判定**：坑覆盖到的每一列都不可破坏 ⇒ **整坑不挖**（否则整坑照旧）。
- **爆炸波必须被不可破坏材质遮挡（T53，2026-09-28 项目所有者指定）**：爆炸波是**标量扩散**，先做一次
  **以爆心为起点的可达性洪泛**（6 邻域；不可破坏材质 = 遮挡体），**只有可达的格**才参与预算结算与栅格化：
  - 被遮挡的格**零改动**、且**不消耗预算**（近侧该挖多少仍是多少）；
  - 栅格化走**"按掩码"**路径（`RasterizeBall` 收 `BlastMask`）—— 只改预算不改栅格化是不够的，
    光滑球面会把岩后的东西一并挖掉；
  - **爆心落在岩体内部 ⇒ 波一格都出不去**（`destroyed == 0`，返回"无改动"是正确结果）；
  - 波**可以绕过**岩体的边缘（洪泛含空气格与可破坏格）—— 与"爆炸波衍射绕过障碍物"一致；
    只有**真正被围住**的格才受保护。**禁止**用"按方向投影阴影"之类会漏掉绕行的近似替代洪泛。
- 挖除结果仍须交给既有的脏块重网格 / 碰撞体同步 / 塌落（[ADR 0012](../../../docs/adr/0012-collision-takeover-by-volumes.md)）流程；**不得**在结算里另起一套写回路径。

## 3. 固定器物

- **状态机**：`Intact → Broken`，本阶段**一次性、不可逆**（修复 / 复原属后续项，未定前不得实现）。
- **状态与表现分离（硬约束）**：
  - 状态是**世界层数据**（`world/prop/`），是"是否已破坏"的唯一事实来源；
  - 表现由**渲染层**消费；**禁止**把状态表达成"材质变黑"之类的渲染态，否则将来替换正式外观时必须改逻辑。
- **触发**：累计伤害 ≥ `prop_damage_threshold`（全局破坏表，缺省 = 单发命中即破）；`destructible = false` 的器物**无视**该阈值。
- **本阶段表现**（项目所有者 2026-09-27 明确指定的分期）：预制外观**留白**，仅把外表**整体变黑**；颜色取自配置（`prop_broken_tint`），**禁止**在代码里硬编码颜色或写死"变黑"这一表现。
- **切换条件**：美术预制外观就绪后替换表现层实现，**不改逻辑**。

## 4. 配置与校验

| 表 | 新增字段 | 校验（违反即**抛异常**，不静默回退） |
| --- | --- | --- |
| `assets/config/materials.toml` | 每个 `[[layer]]` 增 `toughness ≥ 0` | 缺失 / 负值 / 非数 |
| `assets/config/projectiles.toml` | 每个 `[[projectile]]` 增 `damage ≥ 0` | 缺失 / 负值 / 非数 |
| `assets/config/destruction.toml`（新） | `points_per_cubic_block > 0`、`prop_damage_threshold ≥ 0`、`prop_broken_tint` | 缺失 / 越界 / 非数 |

- **禁止**在 `.cpp` 里硬编码任何伤害 / 坚固度 / 阈值 / 颜色（"禁止静默回退"与"禁止第二份常量"两条红线的落地）。
- `toughness` 是**玩法数值**：**禁止**把它打包进渲染 uniform 块（渲染只消费材质表的外观字段）。
- 新增字段时按各表文件头的「版本历史」惯例，决定是否升 `schema_version`（字段语义扩展 ⇒ 升；仅取值调整 ⇒ 可不升，但必须在文件头注明修订）。

## 5. 必测判据（可判定，缺一不可）

1. **纯泥土锚点**：伤害 10 的光球在纯泥土中挖出的腔体 **r ≈ 6 格**（保持既有手感；允许 ±1 格离散误差）。
2. **纯岩石**（**T52 起**）：岩层 `indestructible = true` ⇒ 同参数下**零改动**（不标脏、仍实心）；
   **对照**：同一场景同一预算把材质换成土 ⇒ 正常挖出 **r ≈ 6**（证明"零改动"是材质造成的）。
   （T52 之前的口径是"岩腔更小（`V = 542 格³ ⇒ r ≈ 5.06 格`）"—— `toughness = 5.0` 仍保留，
   把 rock 的 `indestructible` 改回 `false` 即恢复该口径。）
3. **混合材质**：软材质被挖、硬材质**留在原地**（断言"被挖格数 = 预算可负担的格数"且硬材质区零改动）。
4. **不可破坏材质**：爆炸落在其中 ⇒ **零改动**；且**不消耗**预算（相邻软材质仍按全额被挖）。
5. **确定性**：同一输入重复执行 ⇒ 逐体素相同结果（含同距格的次序）。
6. **器物**：`destructible = false` 永不切换状态；`= true` 达阈值切到 `Broken`；**只改表现颜色不得改变状态**（反之亦然）。
7. **配置**：缺字段 / 负值 / 非法 ⇒ 启动期抛异常。
8. **回归**：崩塌落（T29）的 5 项不变量与既有碰撞接管（T28）测试**必须仍全绿**。
9. **破坏的连带后果（T51 / T52 起）**：① **碎块补丁雕刻**（T50）对不可破坏材质同样是**零改动**
   （断言：球心就在岩里 ⇒ 返回 false + 完整网格顶点**逐位相同**）；② **散体回写后不得有悬空体素**
   （降不到支撑的残留一律**清除**并计数，`removedFloatingVoxels`）。
10. **遮挡（T53）**：① **岩墙隔着土腔** ⇒ 墙后**零改动**，而**对照**（墙换成土）被正常挖通；
   ② 被遮挡的格**不消耗预算**（墙前近侧腔体与"没有墙"时**一样大**）；③ **爆心在岩体内** ⇒ 波不外泄、
   连岩块之外的土也零改动；④ **立方岩壳完全围住** ⇒ 只挖壳内、壳外零改动，
   且掩码切断处**不得出现退化 / 绕序反转的三角形**（"画不出来的面"与"会被背面剔除的面"）。

## 6. 禁止项速查

- 在代码里写死伤害 / 坚固度 / 阈值 / 表现颜色。
- 把器物（或其破坏状态）写进地形场。
- 用"外观变黑"之类的渲染态表示"是否已破坏"。
- 逐格结算用随机次序，或用浮点累加决定能否挖下一格。
- 跳过"逐格扣减"、退回"按半径挖球"。
- 未定 ADR 前自行实现"可破坏建造物 / 预制碎块 + 接合"。
- 未经项目所有者确认就扩大可破坏元素的范围（主文件第五节范围控制）。
