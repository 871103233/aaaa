# 输入、玩家控制与 V0.1 玩法设施

涉及主循环与时间步、输入、玩家移动、挖掘与堆建、物件放置、调试设施时读本文件。
**红线条款见主文件第一节红线表**；本文件只写"调用侧必须遵守什么"，世界表示内部规则见 `chunk-and-streaming.md` 与 `meshing-and-render.md`，存档见 `save-and-serialization.md`。

## 1. 主循环与固定时间步（红线 11 的落地细则）

- 逻辑与物理以**固定 `dt = 1/60 s`** 推进，用累加器承接帧间余量；渲染侧用插值系数平滑显示。
- **单帧最多补 5 步**，超出部分直接丢弃，防止卡顿后陷入死亡螺旋。
- 时间源用 `SDL_GetPerformanceCounter` / `SDL_GetPerformanceFrequency`（单调时钟）；
  **不使用 `std::chrono::system_clock`**（会被系统校时影响）。
- **禁止**把可变帧间隔直接传进物理与角色更新 —— 那会让跳跃高度与隧穿判定随帧率漂移。
- 插值系数只用于渲染，**不得**回写进逻辑状态。

## 2. 输入

- 输入一律经引擎核心与平台层抽象：`engine/platform` 负责窗口与事件，再映射为**动作状态**交给 `game/`。
- `world/`、`game/` **不直接读 SDL 事件队列**，只消费动作状态（持续按下 / 本帧按下）。
- 动作状态**每帧采样一次**，在固定步循环之外完成，避免同一帧内多个逻辑步重复消费同一次点击。
- 视角输入驱动**第三人称相机**的 yaw / pitch；pitch 夹在 ±89°；渲染用的相机朝向只在渲染侧插值。

## 3. 角色（胶囊）与第三人称相机

- 角色碰撞体为**胶囊**，由 Jolt `CharacterVirtual` 驱动（ADR 0004）；**禁止**自研 swept AABB 与方块碰撞查询。
- 必须支持：走、跳、上坡、上台阶（台阶高默认 1 格）。台阶抬升**必须**由角色控制器处理，**禁止**用缩小碰撞体改善手感。
- 位置一律整数与 `double`；上传 GPU 前做相机相对偏移转 `float`（红线 6）。
- **第三人称相机**：跟随角色，**必须**具备避障（不穿地形）；相机避障只在渲染侧做，**不得**影响角色逻辑状态。
- 地形碰撞由**地表 tile 的 `HeightFieldShape`** 与**体积块的 `MeshShape`** 共同承担（方案 §5.1）。

## 4. 笔刷式挖掘与堆建（地表高度场）

- 交互为**笔刷式**：一次操作影响以命中点为中心、半径为 R 的一批**地表列**。
- **向下**降低列高度 = 挖掘；**向上**抬高列高度 = 堆建；两者都是**高度场修改**，**禁止**改成方块式的整格增删。
- 操作流程固定：

  1. 由相机射线求与地表的命中点（解析求交，**禁止**逐格 DDA 步进）；
  2. 计算受影响的列集合，按笔刷半径内的权重衰减修改高度；
  3. 把受影响列所属**地表 tile 标脏** → 触发重网格（见 `chunk-and-streaming.md` §7）。

- 操作后**必须 ≤ 1 帧**内可见更新；单次笔刷**只重网格受影响 tile**，**禁止**整世界重网格化。
- 修改**必须**经高度场接口，保持数据为 `int16` 定点（1/16 格）；**禁止**在玩法侧直接操作原始内存。
- 高度取值**必须**夹在世界垂直范围内（0 ~ 512 格）。

## 5. 可挖体积内的三维挖掘

- **三维挖掘只在被标记的可挖区域内允许**（ADR 0004 硬约束 2）。标记之外**禁止**修改体积密度场。
- 标记区域之外，玩家仍可做 §4 的地表笔刷挖掘与堆建 —— 但**只影响高度场**，**不得**创建体积块。
- 三维挖掘流程固定：

  1. 命中点必须落在**已加载且被标记**的体积块内，否则视为不可交互；
  2. 按笔刷球体修改 `int8` 密度值（`d < 0` 实心、`d > 0` 空）；
  3. 把受影响的**体积块标脏** → 触发等值面重网格（见 `chunk-and-streaming.md` §7）。

- **禁止**隐式触发生成：目标块未加载时一律视为"不可交互"，加载只由流式加载器按距离调度。
- **层间过渡**：改动落在体积与地表相接列时，**必须**同批重建该列的地表网格与体积网格，保证无裂缝、无穿模（方案 §2.2 约束 3）。
- 操作后**必须 ≤ 1 帧**内可见更新；单次笔刷**只重网格受影响体积块**。

## 6. 物件放置与建造

- 物件放置与玩家建造归**物件层**：以 **EnTT 实体 + Jolt 碰撞体**表示（ADR 0004 层 ③）。
- **禁止**把放置的物件与建造写入地形场**与**体积密度场（ADR 0004 硬约束 1）：否则会在地表"打出柱子"。
- 放置前**必须**校验：目标位置不与玩家胶囊相交，且不与已有物件碰撞体重叠；校验失败即取消本次放置。
- 放置结果只产生**实体记录**；存档时按"物件与建造"类别独立序列化（见 `save-and-serialization.md` §2）。
- 本阶段**不做**程序化浮空岛与遗迹生成；放置能力只覆盖玩家手动放置的最小集合。

## 7. 调试设施（V0.1 就要有）

- Dear ImGui 运行时面板：帧时间、玩家坐标、笔刷半径、已加载 tile 与体积块数；**可随时开关且不崩溃**。
- 极简 CVar / 控制台：传送、切换 tile 视距、暂停流式加载与重网格。
- 调试设施**不得**成为世界层热路径的一部分；面板数据的采集要走独立统计接口。

## 8. 内存与日志

- 热路径**禁止 `new` / `delete`**：用对象池、句柄、线性分配器；每帧临时数据交给线性分配器，帧末整体重置（红线 10）。
- `shared_ptr` **仅限**加载单元的不可变快照。
- 日志统一走引擎日志接口，**不散落 `std::cout` / `printf`**。
- 热路径用返回值传错误，**不分配、不抛异常**；启动期允许异常。

## 9. 本引用相关测试

- **固定步长**：锁 30 FPS 与 144 FPS 时跳跃高度一致（误差 < 1%）。
- **输入采样**：同帧多个逻辑步不重复消费同一次点击。
- **笔刷更新**：地表与体积的笔刷改动均在 ≤ 1 帧内反映到画面。
- **标记边界**：标记区域之外的三维挖掘被拒绝；地表笔刷在区域外仍生效且不创建体积块。
- **层间过渡**：体积与地表相接处无裂缝、无穿模。
- **物件不写地形**：放置与拆除物件后，地表高度场与体积密度场逐值不变。
- **相机避障**：第三人称相机不穿地形。
- **坐标精度**：相机移至 `x = 10,000,000` 后地表网格无抖动。
