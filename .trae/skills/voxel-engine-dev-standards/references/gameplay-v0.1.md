# 输入、玩家控制与 V0.1 玩法设施

涉及主循环与时间步、输入、玩家移动、方块交互（DDA 拾取 / 破坏 / 放置）、
`assets/blocks.toml`（方块注册表）、`assets/textures/layers.toml`（纹理层号）、调试设施时，**本文件适用**。
红线条款见主文件第一节；本节只写"调用侧"必须遵守什么，区块 / 光照 / 网格化的内部规则见各自引用。

## 1. 主循环与固定时间步（红线 11 的落地细则）

- 逻辑与物理以**固定 `dt = 1/60 s`** 推进，用累加器承接帧间余量；渲染侧用插值系数平滑显示。
- **单帧最多补 5 步**，超出部分直接丢弃，防止卡顿后陷入"死亡螺旋"。
- 时间源用 `SDL_GetPerformanceCounter` / `SDL_GetPerformanceFrequency`（单调时钟）；
  **不使用 `std::chrono::system_clock`**（会被系统校时影响）。
- **禁止**把可变帧间隔直接传进物理或角色更新 —— 那会让跳跃高度与隧穿判定随帧率漂移。
- 插值系数只用于渲染，**不得**回写进逻辑状态。

## 2. 输入

- 输入一律经引擎核心 / 平台层抽象：`engine/platform` 负责窗口与事件，再映射为**动作状态**交给 `game/`。
- `voxel/`、`game/` **不直接读 SDL 事件队列**，只消费动作状态（持续按下 / 本帧按下）。
- 动作状态**每帧采样一次**，在固定步循环之外完成，避免同一帧内多个逻辑步重复消费同一次点击。
- 视角：鼠标相对位移驱动 yaw / pitch，pitch 夹在 ±89°；渲染用的相机朝向只在渲染侧插值。

## 3. 玩家移动与碰撞（调用侧约定）

- 碰撞查询范围 = 玩家 AABB 周围 **3×3×3 个方块**（单位是**方块**，不是 Section）。
- 解算顺序固定：**子步进**（每子步位移 ≤ 0.25 格）→ 逐轴 X / Y / Z 解算 → **自动上台阶**（遇 1 格坎时抬升后试探可否站立）。
- 碰撞盒用精确尺寸（宽 0.6、高 1.8、眼高 1.62）；**禁止**用"缩小碰撞盒"改善手感。
- 位置一律整数 / `double`；上传 GPU 前做相机相对偏移转 `float`。

## 4. 方块交互：DDA 射线拾取

- 用 DDA（Amanatides & Woo）逐格步进，**命中距离上限 5 格**。
- 命中结果必须同时给出**命中方块坐标**与**命中面法线**；放置位置 = 命中坐标 + 法线。
- 命中的方块要**高亮**（V0.1 验收项之一）。
- 破坏 / 放置后：把受影响方块所属 **Section** 标脏 → 光照 BFS 增量传播 → 仅该 Section 重网格化；
  **禁止整 Chunk 重建**。操作后 **≤ 1 帧**内网格更新完成。
- 放置前必须校验：目标格为空气，**且不与玩家自身 AABB 相交**（否则会把玩家卡死）。
- 命中查询**必须跨区块取方块**；目标坐标所在区块未加载时一律视为"不可交互"，
  **不得隐式触发生成**（生成只由流式加载器按距离调度）。

## 5. 方块注册表（`assets/blocks.toml`）

- **唯一数据源**：方块属性（`solid` / `opaque` / `light_level` / `texture` / `hardness`）在启动时
  一次性读入全局 `BlockRegistry`，**不随方块实例重复存储**。
- `id = 0` 恒为空气（`kBlockAir`）。
- **`id` 一经分配不得修改或复用** —— 存档的调色板引用它，改了会让老存档错位。
- 新增 / 修改方块时：同步 `assets/blocks.toml` 与读取代码，并在 `docs/devlog.md` 记录。

## 6. 纹理数组层号（`assets/textures/layers.toml`）

- 用**纹理数组**而非图集：图集在 mipmap 下会渗色，数组每层独立 mip，无接缝问题。
- 所有 tile 尺寸必须一致（当前 16×16）；`max_layers` 为数组容量上限。
- **层号只追加，不复用、不重排**；`index = 0` 保留给"缺失纹理"调试占位。
- 离线打包工具放 `tools/`（目录创建时须在 `docs/file-index.md` 登记）。

## 7. 两份表的交叉一致性（可测）

`blocks.toml` 中每个 `texture >= 0` 的层号，**必须**在 `layers.toml` 中存在；
反向不要求（层可以暂时没有方块引用）。这条应落成单元测试，而不是靠人眼比对。

## 8. 调试设施（V0.1 就要有）

- Dear ImGui 运行时面板：帧时间、区块数、玩家坐标；**可随时开关且不崩溃**。
- 极简 CVar / 控制台：传送、切视距、暂停区块更新。
- 调试设施不得成为 `voxel/` 热路径的一部分；面板数据的采集要走独立统计接口。

## 9. 内存与日志

- 热路径**禁止 `new` / `delete`**：用对象池 / 句柄 / 线性分配器；每帧临时数据交给线性分配器，帧末整体重置。
- `shared_ptr` 仅限区块快照。
- 日志统一走引擎日志接口，**不散落 `std::cout` / `printf`**。
- 热路径用返回值传错误，**不分配、不抛异常**；启动期允许异常。

## 10. 本引用相关测试

- 面剔除：方块堆**内部面数 = 0**；RenderDoc 截帧该堆仅 1 个 draw call。
- DDA：≤5 格内稳定命中且无误判。
- 固定步长：锁 30 FPS 与 144 FPS 时**跳跃高度一致**（误差 < 1%）。
- 坐标精度：相机移至 `x = 10,000,000` 后方块边界无抖动。
- 表一致性：`blocks.toml` 的 `texture` 层号在 `layers.toml` 中均存在（见 §7）。
