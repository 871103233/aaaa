# ADR 0016：倒塌的真实感（爆心冲量 / 材质化物理参数 / 小碎片清除）

- **状态**：已采纳（2026-09-27）
- **相关**：[ADR 0013](0013-destructible-elements.md)（可破坏元素与坚固度）、[ADR 0014](0014-voxel-material-index.md)（体素级材质：本 ADR 的物理参数挂在它上面）、[ADR 0015](0015-structure-units-and-rigid-collapse.md)（结构单元与刚体化倒塌：冲量进入其流程、清除覆盖其"绝不凭空消失"）、[ADR 0009](0009-terrain-material-pipeline.md)（材质表）、`.trae/skills/voxel-engine-dev-standards/references/destructible-elements.md`、`docs/game-design.md`

## 背景

项目所有者 2026-09-27 追问"标准 3A 大作如何让物体掉落更真实"，并选定四项。现状差距（均已定位到代码）：

1. **没有冲量**：`game/rigid_collapse.cpp` 的 `Spawn` 只给"确定性小角速度"（`initial_tilt_speed`），
   线速度恒为零（`physics_world.cpp` 的 `bodySettings.mLinearVelocity = sZero`）⇒ 塔是"垂直掉下来"的，
   没有**被炸飞的势头**（3A 里碎块初速由爆破点决定，见 R6 Siege / Frostbite 的 destruction）。
2. **物理参数全局一套**：`collapse.toml` 的 `mass_per_voxel = 2.4` / `friction = 0.6`，且 `mRestitution = 0` 硬编码
   ⇒ 石、土、草、沙**一样重、一样滑、都不回弹**（3A 用 per-material 的 density / friction / restitution）。
3. **小碎片**：失去支撑的碎渣会各自变成完整刚体（占 `max_active_units` 名额、触发回写与重网格）。
   观感上"炸碎"应表现为**消失**（项目所有者明确要求："浮空小碎片可以直接删除，就当作是炸没了"）。
4. **落地摔断**：AAA 的"塔落地断成几截"需要材质强度做判据 ⇒ **本轮不做**（见「本轮不做」）。

## 决策

### 一、爆心冲量（取代"只有人工倾斜"）

- **输入**：爆心 `C`、影响半径 `R`（来自弹丸表的爆炸半径）、`impulse_speed`（配置，= 爆心的冲量速度，0 = 关闭）。
- **口径（逐体素，确定性）**：体素中心 `p`、到爆心距离 `d = |p − C|`、
  `falloff = clamp(1 − d/R, 0, 1)`、`dir = normalize(p − C)`（`d ≈ 0` 时取 `+Y`，确定性兜底）⇒
  `v(p) = dir · impulse_speed · falloff`。
- **折算成刚体初速**（world 层算一次，随 `CollapseUnit` 带走 ⇒ **可脱离 GPU / Jolt 单测**）：
  - 线速度 `V = Σ v(p) / N`；
  - 角速度 `ω = Σ (r × v(p)) / Σ |r|²`，其中 `r = p − 质心`（球体上的精确解；一般形状是**近似**，见后果 1）。
- **与人工倾斜的关系**：`impulse_speed > 0` 且种子带爆心 ⇒ **用冲量**（真实的不对称来自冲量分布），
  不再叠加人工倾斜；否则退回既有 `initial_tilt_speed`（兜底；配置可关，便于做"只靠外力倾倒"的测试）。
- **"有冲量"的判据 = 折算出的 `V` / `ω` 非零**（实现时补的一条守卫）：整个分量都落在半径之外（或冲量恰好
  对称抵消）时 `V = ω = 0`，此时 `hasImpulse = false` ⇒ **退回人工倾斜**。否则细长的塔会因"半径够不到塔身"
  而**竖直落下却不倒** —— 那正是要避免的观感。

### 二、材质化物理参数（复用 T42 的体素材质通道）

- `materials.toml` 的**每层**新增 `density`（每格³ 质量）/ `friction` / `restitution` / `indestructible`。
  **`schema_version` 保持 4 不变**：四个字段**全部可选**、且缺省值与引入前的**全局口径等价**
  （岩 ≈ 2.4 / 摩擦 0.6 / 弹性 0）⇒ **非破坏性变更**，旧文件不改也能加载（口径与既有的 `subsurface` 一致）。
  非法值（`density ≤ 0`、`friction` / `restitution` ∉ [0,1]、类型错）一律**抛异常**，不静默回退。
- 一个倒塌整体的参数在 **world 层**算一次：
  - **质量** = Σ（各体素材质的 `density`）—— 逐体素累加（体素材质由 T42 的补丁提供）；
  - **摩擦 / 弹性** = **多数材质**的对应值（同票按槽位序号升序 ⇒ 确定性）；
- `collapse.toml` 的 `mass_per_voxel` / `friction` **删除**（单一事实来源 = 材质表；避免两处漂移）。
- 顺带新增 **`indestructible`**（bool，默认 false）：**本轮只用于"小碎片清除"的守卫**（见决策三）。

### 三、小碎片清除（**覆盖** ADR 0015 的"体素绝不凭空消失"）+ 不可破坏守卫

- 失去支撑的连通分量若 **体素数 ≤ `debris_delete_max_voxels`**（配置）⇒ **直接清除**（视为"被炸没了"）：
  **不生成刚体、不回写**，计入 `CollapsePlan` 并打日志。
- **守卫（不可误删）**：该分量只要含**任一 `indestructible` 材质的体素** ⇒ **不删除**，按常规流程处理。
- 与既有策略的关系（**不变**）：**超过 `max_active_units` 的大分量仍"保持原状"**（不删、不塌）。

## 备选方案（已评估）

| 备选 | 未采纳的理由 |
| --- | --- |
| 冲量按"距离平方反比"衰减 | 小半径下容易产生极端速度；**线性衰减**与球体挖除的几何一致、更可控 |
| 角速度用**惯性张量精确解**（Jolt `Shape::GetMassProperties`） | 需要把形状 / 质量属性拉回 world 层（或把世界层逻辑搬进 engine）⇒ 破坏分层与"可脱离 GPU 单测"；球体解已足以产生翻滚。**切换条件**：需要精确自旋守恒时改用引擎层折算 |
| 小碎片"不删、只转静态体" | 玩家看不出区别，却仍保留碰撞与回写成本；项目所有者明确要"当炸没了" |
| 落地摔断本轮一起做 | 有说服力的断裂判据依赖 ADR 0013 的 `toughness`（**未实现**）⇒ 本轮不做（见「本轮不做」） |

## 后果

- **正面**：塔被炸飞并翻滚（冲量）；石 / 土 / 草 / 沙手感不同（质量 / 摩擦 / 弹性）；碎渣不再占名额、不触发重网格（清除）。
- **代价与已知限制**：
  1. **角速度是近似**（球体解），不是真实惯性张量 ⇒ 极端细长体的翻转速度可能与真实有偏差；
  2. **清除 = 质量不守恒** —— 这是**项目所有者显式要求**的放松，**覆盖** ADR 0015 后果 3 的"尽量守恒"口径；
  3. **`indestructible` 目前只是清除守卫**：光球仍能挖除该材质 ⇒ 与"不可破坏"的**字面语义尚未一致**，
     待 [ADR 0013](0013-destructible-elements.md) 的伤害模型（T31）落地后统一；
  4. 冲量让碎块飞得更远 ⇒ 回写区域 / dirty 块更多（重建走 T37 队列，仍受 `max_active_units` 限制）。
- **本轮不做 / 切换条件**：
  - **落地摔断（二次碎裂）**：等 ADR 0013 的 `toughness` 落地（T31）后，按"冲击 × 质量 vs 材质坚固度"判定；
    切分算法 = 沿主轴确定性递归切分，子块继承父块的速度 / 角速度与材质（已登记为阶段计划的 **T44**）。

## 实测（2026-09-27，T43 落地当轮）

- **单测（7 项新增，`ctest --preset debug` 274/274）**：方向朝外 + 随距离衰减（同半径下更远 ⇒ |V| 更小）、
  确定性（同输入两次 `V` / `ω` **逐位相同**）与有限性、无冲量来源时 `hasImpulse = false`（三种情形）、
  质量 / 摩擦 / 弹性按材质、混合分量取多数（同票取更小槽位）而质量逐体素累加、
  小碎片清除的**阈值边界**（= 阈值清除 / 阈值 − 1 保留）、`indestructible` 守卫（同场景对照可证伪）。
- **冒烟（真实操作）**：地标塔（3×5×138 格 = 2072 体素）基座被光球挖断 ⇒
  `失去支撑 2227 体素、整体 2 个、清除小碎片 3 个 / 11 体素` ⇒ 塔**倾角 74°、落点 z 位移 68 格**（被炸飞 + 翻滚 + 远抛）。
- **已知的观测缺口（登记）**：一次 61.4 ms 帧尖峰落在"大单元回写"那一帧，但**三相 CPU 合计仅 22.2 ms**
  （含回写的"逻辑"= 19.95 ms）⇒ ≈39 ms 属于 T38 打点的**未覆盖区**（角色 / 光球顶点上传、uniform 构建、
  限帧与呈现等待）。**不影响本轮结论**（T43 无新增每帧工作），但"主要受限在谁"的判定需要先补打点覆盖。
