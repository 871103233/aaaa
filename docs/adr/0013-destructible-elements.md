# ADR 0013：可破坏元素的分类、材质坚固度与伤害结算

- **状态**：已采纳（2026-09-27）
- **相关**：[ADR 0004](0004-hybrid-layered-world-representation.md)（分层混合世界）、[ADR 0005](0005-config-parsing.md)（配置解析）、[ADR 0007](0007-volume-meshing-algorithm.md)（体积网格化）、[ADR 0012](0012-collision-takeover-by-volumes.md)（碰撞接管与塌落）、`docs/game-design.md` §2.2 / §2.3、`docs/world-setting.md`、`.trae/skills/voxel-engine-dev-standards/references/destructible-elements.md`

## 背景

现状：破坏是**半径驱动**的 —— 光球爆炸半径 6 格，落点若在可挖区域内就直接挖出球腔（`DigVolumeWorld::CarveSphere`），**与材质无关**；区域外走地表爆破。也就是"同一次爆炸在任何地方挖出同样大的坑"。

项目所有者 2026-09-27 提出三条要求：

1. **不同元素可破坏性不同**；
2. **固定器物无法改变外形**（不会被挖出洞），破坏时**切换预制外观**；本阶段预制外观**留白**，只把外表**变黑**以便玩家区分"已被破坏"；
3. **按材质规定坚固程度**：例如光球伤害 10、泥土坚固度 3、岩石 5，每破坏"一个体积"的泥土抵消 3 点破坏能力。

这三条在字面上有四处无法直接施工，必须先定口径（否则规范会自相矛盾或不可判定）：

| # | 问题 | 本文的处理 |
| --- | --- | --- |
| 1 | "无法改变外形（无法被破坏）"与"破坏时可以切换预制外观"互斥 | 拆成**两个正交维度**：几何可变性 / 状态可变性（见 §一） |
| 2 | "一个体积"没有单位 | 钉死为**格³（1 格边长的实心体）**（见 §二） |
| 3 | 按字面（伤害 10 ÷ 泥 3 = 3 格³）与现有手感差约 **900 倍**（现为 r = 6 格 ≈ 904 格³） | 引入**换算系数**（配置项），保留"伤害 10 / 泥 3 / 岩 5"这组直觉数字（见 §二.4） |
| 4 | "变黑"是表现，不是状态 | **状态与表现分离**（见 §三.4） |

## 决策

### 一、元素分类：两个正交维度

**"无法改变外形" ≠ "无法被破坏"。** 元素按两个维度分类：

| 元素 | 几何可变性 | 状态 | 归属层（[ADR 0004](0004-hybrid-layered-world-representation.md)） | 破坏路径 |
| --- | --- | --- | --- | --- |
| **地形体量**（地表高度场 + 可挖体积） | **可变**（任意形状的坑 / 洞 / 隧道） | 无状态 | ① 高度场 / ② 可挖体积 | 伤害预算 → **逐格³ 挖除** |
| **固定器物**（雕塑、机关、建筑构件、阵法设施…） | **不可变**（爆炸不改变它的几何） | `Intact` / `Broken` | ③ 物件与建造 | 伤害达阈值 → **状态切换 + 外观替换** |
| （后续）**可破坏建造物** | 由"预制碎块 + 接合"承担 | 多状态 | ③ 物件与建造 | **另一份 ADR**（见「后果」） |

固定器物再分两种（同一个 `destructible` 开关）：

- `destructible = false`：**完全不可破坏** —— 任何伤害都不改变它的状态（对应要求里的"无法被破坏"）；
- `destructible = true`：**可被破坏，但几何不变** —— 只切状态与外观（对应要求里的"破坏时切换预制外观"）。

### 二、地形体量的伤害结算

#### 1. 单位（全部由配置提供，见 §四）

| 量 | 符号 | 单位 | 来源 |
| --- | --- | --- | --- |
| 伤害 | `damage` | 点 | 弹丸表 `assets/config/projectiles.toml` |
| 坚固度 | `toughness` | 点 / 格³ | 材质表 `assets/config/materials.toml`（每个 `[[layer]]`） |
| 换算系数 | `points_per_cubic_block` | 格³ / 点 | 全局表 `assets/config/destruction.toml`（**手感锚点**） |

#### 2. 结算规则

```
体积预算 V = damage × points_per_cubic_block            （格³）
自爆心向外，按"距爆心距离升序"逐格³ 消耗该格材质的 toughness；
余额不足以破坏下一格 ⇒ 立即停止（该格保留）
```

- **混合材质**因此表现为"**软的先被挖掉、硬的留在原地**"——这是本决策想要的真实行为，也是"只看半径"无法表达的部分。
- 遍历次序**必须确定性**：距爆心同距时按整数坐标的确定性顺序（红线 7，禁止随机）。
- 均匀材质下与半径的关系：`r = (3V / 4π)^(1/3)`。

#### 3. 不可破坏材质

`toughness` 为 `0` 或该材质显式标记不可破坏时：该格**永不被挖除**，且**不参与预算扣减**（它没被破坏）。⇒ 爆炸完全发生在不可破坏材质内部时，"无效果"是正确结果，与器物的行为一致。

#### 4. 数值锚点（可判定）

保留所有者的直觉数字：**光球伤害 10、泥土坚固度 3、岩石坚固度 5**；换算系数取"保持现有手感"：

```
目标：伤害 10 的光球在纯泥土中挖出 r ≈ 6 格 ≈ 904 格³
⇒ points_per_cubic_block ≈ 904 × 3 / 10 ≈ 271
⇒ 纯岩石：V = 10 × 271 / 5 = 542 格³ ⇒ r ≈ 5.06 格
```

即**同一发球在不同材质里挖出的腔体大小不同**（泥 6 格 / 岩 5 格），而相对关系（岩比泥难挖）由 `toughness` 表达。换算系数是**单一手感旋钮**：改它即可整体调"破坏力"，不必改材质表。

#### 5. 与塌落（[ADR 0012](0012-collision-takeover-by-volumes.md)）的关系

塌落的判据与算法**不变**；变的只是"哪些体素被挖掉"（由半径改为预算）。⇒ 塌落的种子（`CollapseSeed`）随之变化，无需改判定。

### 三、固定器物（层 ③）

1. **载体**：EnTT 实体 + Jolt 碰撞体（[ADR 0004](0004-hybrid-layered-world-representation.md) 层 ③）；**绝不写进任何地形场**（红线）。
2. **几何不因爆炸改变**：爆炸不在器物上挖洞、不改变其网格与碰撞体形状。
3. **破坏 = 状态切换**：`Intact → Broken`；本阶段**一次性、不可逆**（修复 / 复原属后续）。
4. **状态与表现分离**（硬约束）：
   - **状态**（`Intact` / `Broken`）是数据，落在世界层（`world/prop/`）；
   - **表现**由渲染层消费 —— 渲染层**不得**成为"是否已破坏"的事实来源。
5. **触发**：该器物累计受到的伤害 ≥ `prop_damage_threshold`（`destruction.toml`，缺省 = 单发命中即破）。`destructible = false` 的器物无视该阈值。
6. **本阶段表现（项目所有者 2026-09-27 明确指定的分期）**：**预制外观留白**，仅把外表**整体变黑**，使玩家能一眼区分"已被破坏"。
   - **切换条件**：美术预制外观资源就绪后替换为正式外观（替换只动表现层，**不改逻辑**）。

### 四、配置落点与校验（沿用 [ADR 0005](0005-config-parsing.md) 口径）

| 表 | 新增字段 | 校验 |
| --- | --- | --- |
| `assets/config/materials.toml` | 每个 `[[layer]]` 增 `toughness ≥ 0`（点 / 格³） | 缺失 / 负值即**抛异常**；`0` = 不可破坏 |
| `assets/config/projectiles.toml` | 每个 `[[projectile]]` 增 `damage ≥ 0`（点） | 缺失 / 负值即**抛异常** |
| `assets/config/destruction.toml`（**新**） | `points_per_cubic_block > 0`、`prop_damage_threshold ≥ 0`、`prop_broken_tint`（占位表现色） | 非法即**抛异常**；**不静默回退** |

`toughness` 是**玩法数值**，**禁止**打包进渲染 uniform 块（渲染管线只消费材质表的外观字段）。

## 备选方案（已评估并否决）

| 备选 | 否决理由 |
| --- | --- |
| 不做材质差异（所有地形一样硬） | 与项目所有者要求、与现实（泥软岩硬）及业界（Minecraft 方块硬度 / 7 Days to Die 方块硬度 / UE Chaos 的 **Damage Threshold** / NVIDIA Blast 的 material toughness）都不符 |
| 器物也做成体素（可被挖出洞） | 与"器物几何不可变、有独立破坏状态"的要求冲突；真要把器物做成可碎结构，走"预制碎块 + 接合"路线（属后续项，另开 ADR） |
| 器物改用"预制碎块 + 接合"直接做真倒塌 | 需要美术预切资产 + 碎块预算 + 存档前置，**不在本阶段**；见「后果」的后续项 |
| 只按半径结算（不逐格扣预算） | 失去"混合材质只挖得动软的部分"这一真实行为，且无法表达"打不动的东西" |
| 把 `toughness` 塞进 `materials.toml` 的渲染 uniform | 玩法数值进入渲染管线 ⇒ 口径漂移；故只共享**材质名**，字段用途分离 |

## 后果

- **正面**：破坏结果**依赖材质**（同一发球在泥 / 岩 / 混合材质处结果不同）；地形体量与固定器物各有清晰的破坏模型；数值全部配置驱动、可验收（"纯泥土 r ≈ 6 格"是可测锚点）。
- **代价与已知限制**：
  1. 本阶段器物**没有实体破坏资产**，只有"变黑"占位（**已由项目所有者确认分期**，切换条件见 §三.6）；
  2. 逐格扣预算使"同一次爆炸的形状**依赖材质分布**" ⇒ 测试必须分别钉死**纯泥土 / 纯岩石 / 混合**三种情形；
  3. 实现要**改写** `CarveSphere` 的判据（半径 → 预算），既有相关测试需同步更新；
  4. **体积无存档** ⇒ 破坏结果与器物状态都不跨会话（沿用的已知限制）。
- **后续 / 切换条件**：
  - 器物预制外观就绪 ⇒ 替换占位表现（仅表现层，无需改逻辑）；
  - **可破坏建造物**（预制碎块 + 接合、真倒塌）⇒ **另开 ADR**，并依赖层 ③ 建造层与体积存档；
  - 材质差异扩展到"作用类型"（例如灵力 / 法术对岩更有效、对木无效等）⇒ 需 ADR + `world-setting.md` 的设定（问 8 / 9）。

    （**2026-09-28 修订**：见下一条）。
- **2026-09-28（T52：岩 = 完全不可破坏）**：项目所有者指定"**岩石材质修改为完全无法击毁无法挖洞，
  具备物理引擎能够被光球打到**"。落地方式 = 把 `materials.toml`（与 `Default()`）里 **rock 层的
  `indestructible` 置 `true`** —— 用的正是本 ADR §二.2 早已定义的开关，**不新增机制、不升 `schema_version`**。
  三条口径据此明确（同一次提交内已同步到 `materials.toml` 表头、`references/destructible-elements.md`、
  `docs/game-design.md`、`docs/engine-capabilities.md`）：
  1. **`indestructible = true` 的完整语义** = 该材质的采样**永不被挖除**：伤害预算对它**跳过且不消耗**
     （`CarveByDamage`）、T50 的**碎块补丁雕刻**同样跳过 ⇒ **地形挖不出洞、岩石残骸打不碎**；
     含该材质的整体**不被"小碎片清除"**（T43 守卫）。
  2. **不受影响的三件事**：密度 / 质量、碰撞体、**命中判定** —— 光球**仍会打在岩石上**（被挡住并引爆，
     只是挖不动），岩石**仍会因失去支撑而作为刚体倒塌**（倒塌不是"破坏"，见 ADR 0015 / 0018）。
  3. **§二.5 的区域外界定被收紧**：区域外只有高度场、无法逐列区分岩 / 土（逐列过滤会在坑面留下"柱子"、
     破坏边界一阶连续），故改为**整片判定** —— 坑覆盖到的每一列都不可破坏 ⇒ **整坑不挖**，否则整坑照旧。
     **副作用（已如实登记）**：山体内部的**岩层现在挖不动**（只有草 / 土 / 沙可挖）；
     **回滚** = rock 的 `indestructible` 改回 `false`（`toughness = 5.0` 仍是可挖时的坚固度）。
- **2026-09-28（T53：岩 = 爆炸波的遮挡体）**：项目所有者指定"**岩石要遮挡爆炸波，保护岩石后的东西不被破坏**"。
  在 §二.2 的结算规则里**插入一条前置步骤**（不动其它任何口径）：
  1. **物理依据**：爆炸波是**标量扩散**，不能穿过不可破坏材质。故先做一次**以爆心为起点的可达性洪泛**
     （6 邻域 ⇒ **不对角**，避免从两块岩的角缝里漏过去），只有**可达**的格才参与②③的预算结算。
  2. **必须连同栅格化一起按掩码**：原实现④用"最后一个被破坏格的半径"栅格化一个**光滑球面**，
     该球面**不看材质**（只跳过不可破坏采样）⇒ 只改②③是不够的，岩后的土照样被球面挖掉。
     故 `RasterizeBall` 新增 `BlastMask` 入参：**不可达的采样保持原状**。
  3. **波可以绕过岩体边缘**（洪泛含空气格与可破坏格）—— 与"爆炸波衍射绕过障碍物"一致；
     只有**真正被围住**的格受保护。**爆心落在岩体内部 ⇒ 波一格都出不去** ⇒ "无改动"是正确结果。
  4. **口径登记**：`references/destructible-elements.md` §二/§五；
     **判据**（`tests/dig_volume_test.cpp`）：岩墙隔开的土腔零改动 + 对照换土被挖通、
     被遮挡格不消耗预算、爆心在岩体内不外泄、立方岩壳只挖内部且掩码切断处**无退化 / 绕序反转三角形**。
