# ADR 0017：落地后的表示按材质分流（刚性保留几何体 / 散体回写并沉降）

- **状态**：已采纳（2026-09-27）
- **相关**：[ADR 0015](0015-structure-units-and-rigid-collapse.md)（结构单元与刚体化倒塌：本 ADR 修订其决策三·5「落定后一律体素化回写」）、[ADR 0016](0016-collapse-realism-impulse-material-debris.md)（爆心冲量 / 材质化物理参数 / 小碎片清除：材质物理字段挂在这里）、[ADR 0014](0014-voxel-material-index.md)（体素级材质）、[ADR 0012](0012-collision-takeover-by-volumes.md)（体积碰撞接管）、[ADR 0009](0009-terrain-material-pipeline.md)（材质表）、[ADR 0018](0018-structural-support-and-representation-preserving-destruction.md)（**修订本 ADR 决策二**"光球命中即惰性体素化"⇒ 改为在**碎块自身补丁上雕刻 + 重网格**、不切换表示；**修订决策五**；并细化决策一为**按材质边界拆子块**）、`docs/game-design.md`

## 背景

项目所有者实测："**当前物体下落时和落到地面以后长得不一样**"。判定为**确认为缺陷**（契约 = 同一物体在"运动中 / 落定"两态之间不得无理由改变表示口径），并给出目标口径：

> 区分物体是刚性的还是非刚性的 —— **岩石落地后不允许发生任何形状变化**，**泥土可以和地面融为一体**，
> **泥土要掉到地上、不能出现悬空的泥土**。

现状（三处机制，均已定位到代码）：

1. **过渡空窗 + 逐块长出**：落定当帧 `RigidCollapseRuntime::Writeback` 立即 `HideSlot`（刚体网格不可见），
   而承载残骸的脏块只**入队**，由 `DestructionProcessor` 按每帧 3 ms / 每帧至少 1 块推进 ⇒ 一次 20 块的落定
   要 **≈20 帧（0.3~0.6 s）** 才补齐 ⇒ "残骸先消失、再一块块长出来"。
2. **旋转体的体素化量化 + 与地面熔成一片**：回写是"体素中心 → 最近整数格"的硬量化，
   掉落中是**独立网格 + 随姿态旋转的法线**，落地后变成同一条倾斜柱的**台阶近似**，
   且与地面共用同一张等值面（轮廓熔进地面）。
3. **边缘材质众数投票**：重网格时 cell 材质取"实体侧 8 角众数"⇒ 残骸与地面交界的 cell 可能被地面材质投赢。

## 决策

### 一、材质分流（新的每层字段 `rigid_debris`）

- `materials.toml` 每层新增 **`rigid_debris`**（bool，**可选、缺省 false** ⇒ 与 T43 的四个物理字段同口径，
  **不升 `schema_version`**）：true = 该材质的碎块落地后**保留几何体**（刚性），false = **回写进地形**（散体）。
- 具体取值：**岩 = true**；**土 / 草 / 沙 = false**（松散介质）。
- 一个倒塌整体按其**表面材质**（即"**露在外面的皮**"用什么材质做的 —— 与渲染网格**同源**的表面 cell 材质直方图：
  遍历与网格器同一批 cell、取实体侧 8 角众数、同票取更小槽位 ⇒ 确定性）决定走哪条路：
  **皮上出现任何刚性材质 ⇒ 走刚性**；一个表面 cell 都没有时才退回"全体体素的多数材质"。
- **为什么不是"全体体素的多数材质"**（T46 当轮实测缺陷）：陡壁**内部**的体素是按该列地表"表层 → 次表层"**派生**的
  （[ADR 0014](0014-voxel-material-index.md)），一处白岩陡壁的内部往往被判成土 ⇒ 一块"看着是白岩"的碎块会被判成散体、
  落地后与泥土一样被量化融合（项目所有者实测现象："**白色的岩石掉落后和褐色的泥土表现状态一样**"）。
  "岩石落地后不允许发生任何形状变化"是硬约束 ⇒ 判据必须取**玩家真正看到的那些面**。

### 二、刚性（岩石）：落定后不回写、保留自身网格与姿态

- 落定后**不做体素化**：Jolt 刚体保留（自然休眠）、网格槽位保留、位姿冻结 ⇒ **形状与外观逐像素不变**。
- 该整体仍留在"活跃集合"里继续做落定检测（被唤醒后可能再次落定、再次保持）。
- **可挖性 = 光球撞上就惰性回写**（项目所有者选定）：`game` 层用**局部 AABB（随姿态旋转的 OBB）**判定
  "光球采样点是否落在某个保留残骸内" ⇒ 命中即把该整体**惰性体素化回写**（形状被量化一次，但**由玩家动作触发**），
  随后按常规被这次爆炸挖除。⇒ 岩石残骸**仍可挖**、且光球**不会穿过看着是实心的岩石**。
- **支撑消失仍会再落**：某体积块的碰撞体重建（被挖 / 塌落）后，与它相交的保留刚体被**显式唤醒**
  （`PhysicsWorld::ActivateBody`）⇒ 守住"承重被破坏 ⇒ 上部不得悬空不动"（ADR 0015 决策一）。
  为什么必须显式唤醒：Jolt 不会因"脚下静态形状被改写"而自动唤醒休眠体。

### 三、散体（泥土 / 草 / 沙）：回写并与地面融合，但**必须接地**

- 落定仍走体素化回写（现状），**新增接地沉降**：回写后凡"**下方为空**"的体素沿本列下落，直到下方有支撑
  （区域底面视作地面）；**整个分量都悬空**（挂在半空）时整体继续下落。
- 判据（可单测）：回写 + 沉降后，该区域**不存在"下方为空"的散体体素**（区域底面除外）。

### 四、网格池与回收（"永久保留"的代价与唯一兜底）

- 池 4 → **16 槽**（每槽容量不变 `98304` 顶点 ⇒ 约 **+51 MB 显存**；启动日志已打印每槽字节数）。
- 刚性残骸**永久保留**（不按距离 / 时间回收）。
- **唯一兜底**：需要新槽位而池已满 ⇒ 把**最旧**的刚性残骸惰性回写腾位（确定序）。
  不这么做的后果是"第 17 块结构以后**不再倒塌**"（`Spawn` 失败会退回体素）—— 那比"最旧那块量化一次"更糟。

### 五、碎块的外观网格**必须自闭合**（T46 当轮实测缺陷）

- **现象**（项目所有者实测）："**掉落的物体部分面没有颜色，从部分角度看过去是透明的，但是物理碰撞真实存在**"。
- **根因**：Surface Nets 网格器的口径是"**每条网格棱由 u/v 下侧的 cell 发射一次**"（见 `volume_mesher.cpp`），
  **相邻块会替对方补上区域边界那圈四边形** —— 而独立碎块**没有相邻块**，于是边界圈的面**整块缺失**：
  从外侧看是敞口的（能看穿），但物理凸包/碰撞体是完整的 ⇒ "看着透明、碰撞却在"。
  实测：一块四周全是空气的悬空石板有 **36 条边界边**（每条只被 1 个三角形用到的无向边）。
- **修法**：`CollapseUnit` 的体素补丁同时带一张**归属掩码**（`patchIsUnit`）；`UnitPatchSampler` 改成
  "采样索引与补丁索引 **1:1**"，且把"**非本整体的实心采样**一律当空气"；`BuildCollapseUnitMesh` 的区域尺寸
  取 `patchSize − 1`、偏移取 `bounds.min ± 1` ⇒ 区域**多覆盖一格 cell**，边界棱有了归属 ⇒ 等值面闭合；
  断口（原本连着未塌实心处）也会生成面。
- **不破坏"与地形同源"**：**原本就暴露在空气中**的那些面，其两侧采样与改前**完全相同** ⇒ 顶点**逐位不变**
  （`UnitMeshIsSubsetOfTheTerrainSurfaceItWasCutFrom` 仍通过）。
- **可证伪判据**：闭合流形中每条无向边**恰被 2 个三角形共用** ⇒ 单测断言 `CountBoundaryEdges(mesh) == 0`
  （覆盖"四周皆空气的悬空石板"与"仍连着未塌实心的悬挑板"两种场景）。

## 备选方案（已评估）

| 备选 | 未采纳的理由 |
| --- | --- |
| 把回写做得更准（按"格被覆盖的体积比"判实心） | 只能**减小**台阶 / 缺角，不能消除（体素分辨率是上限），且**解决不了"轮廓熔进地面"** —— 而"熔进地面"正是岩石不该有的行为 |
| 落定瞬间做交叉淡化（旧网格淡出 / 新地形淡入） | 需要 alpha 混合管线（现在是纯不透明），引擎改动大且只是遮丑 |
| 只把"落定批次"插到队列最前 | 只缩短空窗，形状差依旧 |
| 岩石也不回写但**不可挖** | 会导致光球穿过看着是实心的岩石（世界不自洽）；项目所有者选定"撞上就惰性回写" |
| 刚性残骸按距离 / 时间回收（走远就回写） | 项目所有者选定"**永久保留 + 扩池**"，避免在可感知范围内发生量化 |

## 后果

- **正面**：岩石残骸"长得就是它掉下来的样子"（不再量化、不再熔进地面）；泥土回写融合且**不悬空**；
  两者的差别**由材质表驱动**（未来加"灵石 / 冰 / 木"只需加一行配置）。
- **代价与已知限制**：
  1. **凸包填平的后果被永久化**（[ADR 0015](0015-structure-units-and-rigid-collapse.md) 后果 1）：外观是等值面、
     物理是**凸包** ⇒ 岩石残骸可能"悬在凹处上方"或局部与地形穿插，且**不会再被回写修正**（此前会在落定时被修掉）。
  2. **外观截断会永久化**：单槽容量上限（`98304` 顶点 ≈ 24576 四边形）被超过时只截断外观；
     此前下一次回写会"修好"，现在对保留中的残骸是**永久**的（仅日志告警可发现）。切换条件：提高容量 / 分块多槽。
  3. **显存 +≈51 MB**（16 槽 × 3.18 MB）。切换条件：降单槽容量、或按"同时活跃残骸数"回收。
  4. **刚体长期累积**：每个保留残骸占一个 Jolt 刚体 + 一个网格槽；上限 16，兜底 = 最旧优先回写。
  5. **光球命中的精度**：用局部 AABB 近似凸包 ⇒ 可能比真实凸包**早一点**触发（间隙 ≤ AABB 与凸包的差）。
     切换条件：改用精确凸包平面 / Jolt 窄相点查询。
  6. **散体沉降只保证"不悬空"**，不保证"摊平"（安息角 / 散体物理未做）；
     泥土回写后的"融合"仍表现为**台阶式的堆体**（体素分辨率上限）。
  7. **刚性残骸不再进入 T33 的支撑检查**（它是刚体，不参与逐体素判定）——
     支撑消失靠"碰撞体重建 ⇒ 唤醒"这条通路兜底，不是统一判定。

## 本轮不做 / 切换条件

- **散体的真实摊平**（安息角、颗粒堆）——需要散体物理，属新方向。
- **刚体参与支撑检查的统一判定**（现在唤醒兜底已够：静态形状被改写是唯一会改变其受力的来源）。
- **精确凸包命中**（见后果 5）。

## 「世界内一致性」两关

- **真实世界**：岩石落地不变形、泥土落地摊并融入地面、泥土不悬空 —— 与常识一致；
  "光球打到岩石残骸它会碎成体素"可解释为"被再次击中后碎裂"。
- **修仙世界**：与 `world-setting.md` 无冲突；该文 §3 第 9 问（"坍塌规则是否被法术改写"）仍待补，
  本 ADR 提供了**实现侧旋钮**（`rigid_debris`）供将来区分"凡石 / 灵石"。

## 实测（2026-09-27，T46 落地当轮）

- **单测（7 项新增，`ctest --preset debug` 281/281）**：**表面材质分流**（含**同票取更小槽位**，
  以及回归用例"**体积里土占多数、但皮上有岩 ⇒ 仍判刚性**"）、
  散体回写 + 沉降后**区域内不存在"下方为空"的实心体素**、刚性回写**不沉降**（体素留原位）、
  命中判据 `LocalAabbContainsPoint` **随姿态旋转**（同一世界点在单位姿下"在盒内"、转 90° 后"在盒外"）、
  `PhysicsWorld::ActivateBody` 容忍非法句柄且**不扰动静止刚体**、
  **独立碎块（四周皆空气）网格闭合**、**仍连着未塌实心的悬挑板网格闭合**（后两项断言 `CountBoundaryEdges == 0`）。
  **单测抓到两个真 bug**：
  ① 接地沉降最初写成"落完再腾空" ⇒ 列里留下**一串本应为空的实心格**（假支撑），同列上层体素因此停在半空
  —— 这正是"泥土不能悬空"该有的可证伪判据；
  ② 独立碎块的等值面**在区域边界敞口**（悬空石板实测 **36 条边界边**）⇒ 见决策五，项目所有者的
  "部分面透明、碰撞却真实存在"由此复现并修复。
- **当轮缺陷修复（项目所有者实测两条，均为真 bug）**：
  ① "白色的岩石掉落后和褐色的泥土表现状态一样" ⇒ 判据由"全体体素的多数材质"改为"**表面材质**"（决策一）；
  ② "掉落的物体部分面没有颜色、从部分角度看过去是透明的，但物理碰撞真实存在" ⇒ 碎块网格闭合（决策五）。
  两条都补了能复现的回归测试（见上）。
- **冒烟（真实操作）**：`岩石残骸保留（T46）：体素 2057 个、倾角 6°（**不回写**）`，另 436 / 28 / 772 / 706
  体素岩块同理（倾角 4°~36°）；3 次落定回写含 **接地沉降 48 / 36 / 51 个**（散体）；
  `岩石残骸被唤醒（T46）` **61** 条；网格池 **16 槽**；**无 ERROR**。
- **未满足 / 未触发（如实登记）**：① 判据"无 > 50 ms 单帧"本轮**未满足**（1 条 53.5 ms，
  逻辑 49.04 ms ≈ 全是**爆炸当帧**的 T33/T37 既有成本，与 T46 无关）；
  ② **光球命中保留残骸 ⇒ 惰性回写**这条路径本轮冒烟**未实际命中**（多次瞄准先打到地形 / 落空）
  ⇒ 仅由单测 + 代码路径覆盖，已登记人工验收步骤；③ **池满腾位未触发**（同时最多保留 6 个）。
