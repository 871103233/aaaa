# ADR 0018：结构求解与破坏的表示守恒（连通域支撑 / 自身补丁雕刻 / 物理查询命中 / 按材质分区）

- **状态**：已采纳（2026-09-27）
- **相关**：[ADR 0015](0015-structure-units-and-rigid-collapse.md)（**修订**其"支撑检查邻域 = 被改动采样 ± (悬挑 + 1) 格、只做一次"的口径）、[ADR 0017](0017-landing-by-material-rigid-vs-granular.md)（**修订**其决策二"光球命中即惰性体素化"与决策五，并细化决策一"一个整体一种材质行为"）、[ADR 0016](0016-collapse-realism-impulse-material-debris.md)（碎块物理参数与小碎片清除）、[ADR 0014](0014-voxel-material-index.md)（体素级材质：材质分区的数据基础）、[ADR 0012](0012-collision-takeover-by-volumes.md)（体积碰撞接管）、`docs/plans/v0.1.md`（T47~T50）

## 背景

项目所有者实测四条（均为**确认为缺陷**，契约 + 机制见下），并给出总口径：

> 长条物体里**岩石和泥土都存在的** —— **泥土掉落后一直下坠到存在支点是对的，岩石应该始终不变**。

| # | 现象 | 被违背的契约 | 机制（定位到代码） |
| --- | --- | --- | --- |
| BUG1 | 长条两端支点都破坏后，**中段不落** | "承重被破坏 ⇒ 上部不得悬空"（ADR 0015 决策一） | 支撑检查是**固定窗口 + 一次判定**：水平窗口 `reach = ceil(max_cantilever_blocks) + 1 = 5` 格。距任何破坏点 > 5 格的**中段从不进入任何一次求解** ⇒ 永远是地形、永远不落。`AwakenIntersecting` 只救济**已抽出**的保留残骸，对"仍是地形的中段"无救济 |
| BUG2 | 破坏长条时它**又发生形变** | "岩石落地后不允许**任何**形状变化"（ADR 0017 决策一） | 光球命中保留残骸 ⇒ `RetireRetainedAt` ⇒ `WritebackCollapseUnit` **体素化**（体素中心 → 最近整数格硬量化 + 落位偏移找空位）⇒ 整块轮廓被改。ADR 0017 曾把"被打中时量化一次"登记为可接受代价，**项目所有者本次否定该代价** |
| BUG3 | 部分情况下**仍有面透明** | 外观网格必须闭合（渲染与碰撞同源） | **根因未定**。已排除"材质缺失导致透明"：片元 `o_color.a` 恒为 1 ⇒ 只能是**缺面 / 洞**。候选：① 网格池容量截断（按四边形丢尾部 ⇒ 对保留残骸是**永久**洞）；② 仍有未覆盖的敞口场景；③ 地形 ↔ 体积交界缝 |
| BUG4 | 掉落中**打不中**，落地静止后才能打中 | 光球不得穿过"看着是实心"的物体（ADR 0017 决策二） | `GameOrbWorldQuery::IsSolid` 只认 **`retained == true`** 的残骸。飞行中的整体体素**已被抽出**（体积里是空的）且尚未 `retained` ⇒ 被判为空气 ⇒ 光球穿过 |

四条指向**同一个架构性结论**：ADR 0017 引入的"刚体网格 ⇄ 地形体素两种表示来回切换"，在**结构求解、破坏、命中**三处都露了馅。业界（Teardown / UE Chaos / Red Faction）的一致做法是：**范围由结构拓扑决定、破坏在单一表示内完成、命中交给物理引擎**。

## 决策

### 一、支撑求解的范围改为「连通域」而不是「固定窗口」（修 BUG1）

- **scope**：以**被改动采样**为起点，对实心体素做**连通域洪泛直至结构边界**（不再用 `reach` 截断范围）。
  该连通域即"可能受本次破坏影响的整个结构"。
- **判据不变**（避免与 ADR 0015 冲突）：域内仍按"① 纵向接地（自区域底面连续实心）→ ② 同层实心连通横向传播
  `max_cantilever_blocks` 步"求**支撑体素**集合；其余实心体素 = 失去支撑 ⇒ 按 6 邻域连通分量分组 ⇒ 刚体化。
  改动只在 **scope**，不在物理判据。
- **预算与上界**（SKILL 第四节「所有重活都必须离开渲染帧」）：洪泛的采样数上界沿用 `kMaxRegionSamples`（8M）；
  超界 ⇒ **告警 + 保守回退**到现行固定窗口（"这次没倒"优于"卡住一帧"）。实现按
  **消除 > 下沉 worker > 按帧预算切分** 的优先级处理，并在计划条目里写清"最贵一步在哪个线程 / 单帧最坏多少 ms"。
- **确定性**：洪泛的扫描与邻接顺序固定（沿用现有 x → y → z、±x/±y/±z 的确定序）。

### 二、破坏时**不切换表示** —— 在碎块**自身补丁**上雕刻并重网格（修 BUG2）

- 命中保留残骸时**不再体素化回写**，改为：在它的 `patchDensity` 上做**与地形同口径的球体平滑挖除**
  （复用 `CarveSphere` 的数学），再用**同一份 Surface Nets** 重网格化（`BuildCollapseUnitMesh`）。
- **不变量（可判据）**：等值面是补丁采样的**纯函数** ⇒ **未被挖到的区域，顶点逐位不变**。
  这条把"岩石始终不变"从"靠自觉"变成"可证伪"。
- 随后按**剩余体素**重建刚体（复用同一网格槽位）；剩余体素 ≤ `debris_delete_max_voxels` ⇒ 整体删除。
- 依据：T42 已建立"掉落中 / 落定不换表示"，本决策把**"被破坏"这一态**也纳入同一条口径
  （三态 = 运动中 / 落定 / 被破坏）。

### 三、命中判定接入**物理场景查询**（修 BUG4）

- `PhysicsWorld` 增场景查询（Jolt `NarrowPhaseQuery`：射线段 / 球扫）。光球的"是否实心"改为
  **地形与体积按现行口径（谁画谁挡同源）+ 动态刚体一律走物理查询**。
- 副产品：**覆盖"飞行中"这一态**（无需任何状态记账）、命中使用**真凸包**而非 OBB ⇒ ADR 0017 后果 5
  （"可能早一点触发"）随之消掉；不再需要"每次查询扫全部活跃整体"。
- 保留残骸的手工 OBB 判定（`ContainsRetainedPoint`）随之下线。

### 四、一个整体按**材质边界**拆成子块（回答"长条里岩石与泥土同时存在"）

- 现状：`CollapseUnit::rigidDebris` 是**整块一个 bool** ⇒ 一个整体只能有一种落地行为，
  混合材质的长条必然有一半表现不对。
- 决策：把抽出的连通分量**按材质一致性再划分为子块**（同材质 6 邻域连通 ⇒ 一个子块），
  每个子块**独立**决定行为与刚体：
  - **岩（`rigid_debris = true`）子块** ⇒ 保留几何体、**始终不变**（含被破坏时，见决策二）；
  - **土 / 草 / 沙（`false`）子块** ⇒ 回写并与地面融合，且**接地沉降**（下坠到有支撑为止，ADR 0017 决策三）。
- 子块仍由原连通分量切出 ⇒ 与 ADR 0015"连通分量 = 一个整体"的精神一致（子块是该分量内**材质一致**的部分），
  不引入新的"整体"定义。
- 划分确定序：按**体素的 x → z → y 扫描序 + 6 邻域洪泛**切子块（同材质才算同一子块），
  同一输入永远得到同一划分（红线 7）；子块的行为按 `materials.toml` 的 `rigid_debris` 取该子块的材质决定。

### 五、BUG3 先诊断、后修（不猜根因）

- 在 `docs/plans/v0.1.md` 登记 **T47**：Debug 期对每个整体网格做**边界边自检**（复用测试里的
  `CountBoundaryEdges` 口径），非 0 即 WARN 出（体素数 / patch 尺寸 / 边数 / 是否被容量截断）；
  同时把容量截断 WARN 补上体素数。
- 判据：能**指名**是候选 ①/②/③ 中的哪一个 ⇒ 再决定修法（① ⇒ 池容量与回收口径；② ⇒ 补敞口场景；
  ③ ⇒ 与 ADR 0011 的层间过渡一并处理）。**根因未定前不改外观网格代码**。

## 备选方案（已评估）

| 决策 | 备选 | 未采纳的理由 |
| --- | --- | --- |
| 一 | 只把窗口从 ±5 放大到 ±N | 只把失效距离**推远**，长条超过 2N 仍会漏（BUG1 未消灭） |
| 一 | 维护**持久结构图**（Chaos 的 support graph），增量更新连接与支撑 | 更接近 3A、且免去每次洪泛，但需要新的数据结构 + 增量维护 + 失效检测；登记为**切换条件**（洪泛成为瓶颈时再上） |
| 一 | 每次改动全图重算 | 成本无上界，且违反"重活离开渲染帧" |
| 二 | **预切分碎块**（Voronoi / UE Chaos 式）：生成时预切成片，破坏 = 移除 / 解开碎块 | 碎裂感与鲁棒性最好，但需要新增切分系统 + 碎块物理管理，属新方向 ⇒ 登记为后续任务 |
| 二 | 网格布尔（CSG）切割 | 需要健壮布尔库（新依赖 + 数值鲁棒性风险），当前依赖最小化原则下不做 |
| 二 | 维持"命中即惰性体素化" | **项目所有者本次明确否定**（"破坏这个长条时物体又发生了形变"） |
| 三 | 手工把"活跃中的整体"也纳入 OBB 判定 | 仍是 OBB 近似 + 每次查询 O(活跃数)，且"实心与否"继续靠手工记账维护 |
| 四 | 维持"一个整体一种行为" | 混合材质长条必然有一半表现不对（正是实测现象） |
| 四 | 逐体素决定行为 | 物理上不成立：一个刚体必须整块一致 |

## 后果

- **正面**：① 长条中段不再悬空（"承重被破坏 ⇒ 上部不得悬空"在**整段跨度**上成立）；
  ② 岩石在"运动中 / 落定 / **被破坏**"三态形状一致（可用"未触及区域顶点逐位相同"证伪）；
  ③ 掉落中被击中成为可能（不再依赖状态记账，且用真凸包）；
  ④ 岩 / 土共处的长条各按各的材质表现。
- **代价与已知限制**：
  1. **当帧成本上升**：洪泛 + 雕刻 + 重网格都在爆炸 / 命中的当帧。必须按帧预算或下沉 worker；
     与 **T45（帧尖峰打点的覆盖缺口）** 耦合 —— 不补打点就无法自证没有制造新卡顿。
  2. **雕刻后凸包会变**：物理体积随剩余体素重算，凸包**填平凹形**的问题仍在（ADR 0015 后果 1），
     且"被雕刻出的凹腔"在物理上是凸包、在渲染上是等值面 ⇒ 两者仍可能不一致。
  3. **按材质拆子块会把一个结构变成多个刚体** ⇒ 同时活跃刚体数上升（网格池 16 槽的压力变大）；
     需要"子块数上界 + 超界合并/清除"的兜底（与 `debris_delete_max_voxels` 同源）。
  4. **洪泛的上界回退**是"显式降级"：超界时回到现行固定窗口 ⇒ 该次仍可能漏掉远端中段（有 WARN 可查）。
  5. **BUG3 未修完之前**，"仍有面透明"可能由容量截断造成 —— 而决策二让残骸长期保留 ⇒ 该洞**永久**。
     T47 的诊断优先于其它改动实施（先拿到证据）。
- **不改的东西**：`max_cantilever_blocks` / `settle_*` / `impulse_speed` / `debris_delete_max_voxels`
  等**数值口径不变**（本次只改 scope 与表示），`collapse.toml` 的 `schema_version` 不变。

## 本轮不做 / 切换条件

- **预切分碎块（Voronoi / Chaos 式）**：切换条件 = "破坏的真实感"成为下一轮的验收主题，或雕刻路径出现
  无法解决的鲁棒性问题。
- **持久结构图（support graph）**：切换条件 = 洪泛成为实测瓶颈（帧尖峰或上界回退频繁触发）。
- **散体的真实摊平**（安息角 / 颗粒堆）：仍属散体物理，未做。
- **精确凸包的物理外形**（凹形分解）：见后果 2。

## 「世界内一致性」两关

- **真实世界**：岩体被破坏后**不会变形**（只是少了被炸掉的部分）、泥土**下坠到有支撑为止**、
  悬空的结构**必须落**、看得见的东西**打得到** —— 四条都与常识一致。
- **修仙世界**：与 `docs/world-setting.md` 无新增冲突；"岩 / 土 / 草 / 沙"的可破坏与形态差异由
  `materials.toml` 驱动，将来区分"凡石 / 灵石"只需加配置行。"被毁之物是否被炼化 / 复原 / 引动异象"
  仍待该项目所有者设定（该文 §3 第 9 问未决）。
