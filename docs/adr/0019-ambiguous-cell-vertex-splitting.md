# ADR 0019：等值面网格的**歧义处置** —— 按实体侧连通分量拆顶点（不切到 Marching Cubes）

- **状态**：已采纳
- **日期**：2026-09-29
- **相关**：ADR 0007（Surface Nets 起步；本 ADR **落实其"切换条件"之一**）、ADR 0017（碎块外观网格闭合）、ADR 0018（表示守恒 / 外观网格闭合自检）
- **触发条件来源**：ADR 0007「切换条件」第 2 条 —— "若 SN 在实现中遇到**拓扑歧义**导致可见错误（例如极薄壁两侧粘连）→ 可切换 Marching Cubes"。

## 背景

项目所有者 2026-09-28 实测："爆炸破坏处**偶发某个面透明 / 未染色**"（T55 / 原 BUG3）。
T47 的外观网格闭合自检（`vx::CountBoundaryEdges`，判据见 ADR 0017 决策五）在**倒塌整体的外观网格**上
报出非 0（实测 1 条 / 20 条），而地形与洞的网格一直判 0 ⇒ 问题只在**整体补丁**那条网格化路径上。

T55 取证把它复现成一个最小固件（`tests/volume_mesher_test.cpp`）：
**两个对角相邻的实心采样点**（网格面 `x=3` 上，(3,3,3) 与 (3,4,4)）⇒ 该面四角符号成**棋盘格**。
修前实测：`边界边 1`、退化 0 —— **与游戏内 WARN「边界边 1 条」同签名**；修后：`边界边 0`。

机制（两条同源）：

- **歧义 cell**：8 个角里实体侧角按"**共棱**"分成 ≥2 个不连通分量（例：对角实心）。
  Naive Surface Nets **每个 cell 只放 1 个顶点** ⇒ 两片本应分开的表面被**捏合**成一点 / 一条线。
- **歧义面**：某个网格面（grid face）四角成棋盘格时，它的 **4 条棱全部**与表面相交 ⇒
  该面两侧 cell 顶点之间的那条网格边会被**多达 4 个四边形**共用（非流形）。
  `CountBoundaryEdges` 的判据是"无向边不是**恰被 2 个**三角形共用"，故把这条边计为 1 条边界边。

后果 = 面缺失 / 四边形自交 / 绕序翻转 ⇒ 背面剔除（`cull_mode = CULLMODE_BACK`，片元恒写 `alpha = 1`）后，
屏幕上就表现为"**某个面透明、看得见后面**"。

## 决策

**保留 Surface Nets 家族，新增"按实体侧连通分量拆顶点"**（即 Manifold Dual Contouring 的通行做法）：

1. 一个 cell 内，**实体侧角之间以"共棱"（角下标 Hamming 距离 = 1）连通**；连通分量数 = 该 cell 的顶点数。
2. 位置 = **该分量所辖的那几条棱**的交点均值（单分量时 = 全部跨面棱，与旧实现同序同值）。
3. 四边形发射时，4 个邻接 cell 各取"**它与本网格棱同一分量**"的那个子顶点
   （`cellEdgeVertex` + `kQuadCellLocalEdge[axis][slot]`）。
4. **单分量 cell 的偏移恒为 0** ⇒ 输出与引入本机制前**逐位相同**，"与地形同源""表示守恒"两条既有判据不受影响。

**不切换到 Marching Cubes。**

## 备选方案与取舍

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| **SN + 按实体侧连通分量拆顶点**（采纳） | 留在 SN 家族（换网格算法成本最小）；修非流形；单分量 cell 逐位不变 | 歧义 cell 多 1 个顶点；每 cell 多 12 B 临时数组 | **采纳** |
| **Marching Cubes + 顶点位置后处理**（ADR 0007 原定切换） | 最成熟、无歧义问题 | 表驱动（256 case）、**顶点位置在 case 之间跳变**（与"平滑手感"冲突）；实现更重；**破坏时的表示守恒 / 与地形同源更难保证** | 备选（保留给其它触发条件） |
| **只丢弃零面积三角形** | 改动极小 | 实测**不能**修非流形：边界边由"4 个三角形共用"造成，与面积是否为零无关；也不修自交 / 捏合 | 不采纳 |
| **维持每 cell 单顶点** | 零改动 | 缺陷仍在（面透明） | 不采纳 |

## 后果

### 正面

- 外观网格回到**流形 / 闭合**：`CountBoundaryEdges == 0` 重新成为可用的回归判据（T47 自检有意义）。
- 既有判据**零回归**：区域入口与整块逐位相同、子区域与整块在世界空间一致、碎块网格闭合、球面面积 / 法线 / 材质全绿。

### 负面 / 必须承受的代价

- **歧义 cell 顶点数 +1**：本次最小固件 14 → 16 个顶点，三角形数不变（24）。
- 每 cell 额外 **12 B** 的临时数组 `cellEdgeVertex`：32³ 块约 **431 KB** 临时内存（随调用释放，非常驻）。
- **不解决"锐利硬边"**：岩壁 / 建筑硬边仍会被磨圆 —— 那仍是 Dual Contouring 的职责（ADR 0007 不变）。

## 何时需要重新审视

1. 需要"锐利硬边"的美术诉求 ⇒ 升级 **Dual Contouring**（ADR 0007 的切换条件不变，本 ADR 不影响）。
2. 若歧义处置成为性能瓶颈（临时内存 / 顶点数）⇒ 评估"只对歧义 cell 分配偏移表"。
3. 若歧义 cell 的**法线**（当前各子顶点共用 cell 级梯度）在视觉上可辨 ⇒ 评估按分量算梯度。
