# ADR 0007：可挖体积的网格化采用 Surface Nets 起步

- **状态**：已采纳
- **日期**：2026-09-25
- **相关**：ADR 0004（可挖体积层）；ADR 0008（体积尺寸与密度精度）；`SKILL.md` 待收敛项 3；`docs/plans/v0.1.md` P3
- **收敛**：`SKILL.md` 待收敛项 **3**（体积网格化算法）——本 ADR 落地后该项关闭

## 背景

可挖体积是"**代码层面是格子、玩家看到平滑曲面**"这条需求的核心载体：数据是有符号距离场（SDF），
渲染网格必须由**等值面提取**得到。算法选择直接决定三件事：

1. **平滑度**与顶点位置的连续性（影响挖掘时的视觉稳定性）；
2. **实现与调试成本**（这是 V0.1 的关键路径）；
3. **后续 LOD 与变形**的难度。

需求已明确了两点约束：① 体积**只在标记区域内存在**（ADR 0006），规模有限；
② 地表走高度场，**体积不需要覆盖全世界**，因此不必与高度场共用一套 LOD 策略。

## 决策

**采用 Naive Surface Nets（SN），密度用 `int8` 距离场，块尺寸 32³ 体素（含 33³ 采样）。**

理由（按权重排序）：

1. **每个 cell 最多产生 1 个顶点**：顶点位置由该 cell 内边交点平均得到，**随密度值连续变化** ——
   玩家挖掘时表面**不会突然跳变**，这是"平滑手感"的直接来源。
2. **实现最简**：不需要 Marching Cubes 的 256 项查表与表驱动的三角化，也不需要 Dual Contouring 的 QEF 求解；
   代码量约为 MC 的一半，是 V0.1 关键路径上风险最低的选择。
3. **拓扑规整**：每个 cell 一个顶点，便于按块分块、按块重网格，且**块间共享边界采样**即天然无接缝
   （与 ADR 0004 硬约束 3 一致）。
4. **后续 LOD 友好**：虽然体积在 V0.1 不上 LOD，但 SN 的顶点连续性是将来"低分辨率体积与高分辨率体积过渡"的前提。

配套约定：

- 密度语义：`d < 0` 为实心、`d > 0` 为空、`0` 为表面；`int8` 表示 ±1 格范围内的近似距离（精度见 ADR 0008）。
- 网格化**作用域 = 单块（32³）**，读取邻块边界采样；**块边界必须共享采样值**，不得各自独立生成。
- 顶点位置以**块内定点坐标**存储（避免 `float` 承担世界定位，符合既有红线 6）。
- 法线由**密度场梯度**计算（比三角形面法线平滑），并写入顶点属性。

## 备选方案与取舍

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| **Surface Nets**（采纳） | 每 cell ≤1 顶点、位置连续、实现最简、拓扑规整 | 无法表达锐利棱角（岩壁/建筑硬边会被磨圆） | **采纳（V0.1 起步）** |
| **Marching Cubes** | 最成熟、资料最多、三角化质量稳定 | 表驱动（256 case），**顶点位置会在 case 之间跳变** → 变形与 LOD 过渡更难看；实现更重 | 备选 |
| **Dual Contouring** | 能保留锐利特征（QEF 求解顶点位置） | 实现最重、需处理 QEF 退化与拓扑分裂，V0.1 关键路径上风险高 | 备选（后期需要锐边时升级） |
| **Transvoxel** | 专为跨 LOD 边界缝合设计 | 复杂度高于 SN，而 V0.1 的体积不上 LOD | 备选（体积需要 LOD 时再评估） |

**切换条件（写明可触发）**：

- 出现"岩壁、洞窟边、废弃矿道需要**锐利硬边**"的美术诉求 → 升级 **Dual Contouring**（本 ADR 变为部分被取代）。
- 若 SN 在实现中遇到**拓扑歧义**导致可见错误（例如极薄壁两侧粘连）→ 可切换 **Marching Cubes + 顶点位置后处理**。
- 若体积将来需要与邻块做 LOD 过渡 → 评估 **Transvoxel**。

## 后果

### 正面

- V0.1 的网格化路径风险最低：无查表、无 QEF、每块重网格成本可预测。
- 挖掘时表面连续变化，视觉上符合"平滑、不像方块"的硬需求。
- 与地表的层间过渡只需处理"体积顶部接管该列高度"一处（ADR 0004 硬约束 3）。

### 负面 / 必须承受的代价

- **棱角被磨圆**：所有可挖体积内的硬边都会呈圆滑过渡。若这是问题，需按上面的切换条件升级 DC。
- `int8` 距离场在陡壁/薄壳处会有**台阶感与 alias**（密度精度问题，见 ADR 0008 的重审条件）。
- 重网格成本高于方块贪婪合并，单次大笔刷可能触发多块重建 → 必须异步 + 每帧预算上限（见 ADR 0008）。

## 何时需要重新审视

1. 美术要求出现"必须有硬边"的内容（岩壁、矿道、人工洞窟）→ 升级 Dual Contouring。
2. 单次笔刷重网格成本超出 ADR 0008 的每帧预算 → 评估更小的块尺寸或增量更新策略。
3. 体积需要 LOD → 评估 Transvoxel。
