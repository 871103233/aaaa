# V0.1 开发计划

- **阶段目标**：验证"**平滑地形 + 可挖可堆 + 胶囊体自由活动**"这条主链路 —— 一个能挖能堆的平滑地形块，外加一个与地表相通的洞穴体积。
- 方向依据：[ADR 0004](../adr/0004-hybrid-layered-world-representation.md)（分层混合世界）；现行方案见 [ADR 索引](../adr/README.md)
- 规则：[SKILL.md](../../.trae/skills/voxel-engine-dev-standards/SKILL.md)
- 状态：进行中（前置条件未清）
- 最后更新：2026-09-25

> - 本文件是**计划与进度**，不写技术结论；选型与理由一律看方案文档与 `docs/adr/`。
> - **验收权威**：`tech-plan-v1.3.md` §8 的 V0.1 验收标准**已随 ADR 0004 作废**；在迁移任务 M1 完成前，
>   **V0.1 的阶段目标与验收以本文件 §2 / §4 为准**（M1 落地后回填 `tech-plan-v2.0.md` §8 并与此处保持一致）。
> - **任务落点**：世界层的目录结构属 v1.3 §9.2、同样被取代，故下表中世界层任务的"落点"为**建议值**，待 M1 定稿后回填。

- **全世界三维体素**（ADR 0004 已明确不采纳）。
- **程序化浮空岛 / 遗迹、玩家自由搭建**：本阶段**只做飞行元素**（实体层），浮空与建造后置。
- **人物模型与骨骼动画**：本阶段只用**胶囊体占位**。
- 后置阶段项：LOD、遮挡剔除、存档落盘、Jolt 动态刚体、粒子与音频。
- SKILL「范围控制」表中的五项暂缓项（场景编辑器、脚本系统、网络联机、多渲染后端、自研 ECS）**一项都不启动**。
