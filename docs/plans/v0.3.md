### 1.2 T68 施工细则（**2026-10-05 开工前补全**，符合 SKILL「任务下发」节）

- **范围**：引入 `assimp`（vcpkg 端口）并新增**模型导入能力** —— glTF / `.glb` 的**静态网格**与**蒙皮网格**、`skin` 的关节与逆绑定矩阵、骨骼动画（TRS 通道）的**加载与采样**。
  **明确不做**（防蔓延）：**不接渲染**（拖影 / 蒙皮着色器、主角替换 = **T69**）；不改世界层；不引入场景图 / 材质图系统；不做 FBX / OBJ 等其它格式的额外验证（Assimp 顺带支持，但不作为验收项）。
- **顺序**（每步可独立验证）：
  1. 依赖入库：`vcpkg.json` 增 `assimp` → 同步 `NOTICE.md` / `docs/file-index.md`；configure + 构建通过。
  2. `engine/render/model_loader.{hpp,cpp}`：公共头**只暴露自有类型**（pimpl 隔离 Assimp，同 `physics_world` 隔离 Jolt 的口径）；实现 glTF / `.glb` 解析 → 自有 `Model` 结构。
  3. **动画采样纯函数**：`SamplePose`（TRS 关键帧 → 局部矩阵）+ `ComputeSkinningMatrices`（`GlobalJoint × inverseBind`），**确定性**（同输入逐位一致）。
  4. 测试夹具 + `tests/model_loader_test.cpp`。
- **落点**：`vcpkg.json`、`NOTICE.md`、`docs/file-index.md`、`docs/engine-capabilities.md`（"资源管理"行）、**新增** `engine/render/model_loader.{hpp,cpp}`、`engine/CMakeLists.txt`、**新增** `tests/model_loader_test.cpp` + `tests/fixtures/`（**测试夹具，进仓库**）、`tests/CMakeLists.txt`。
- **验收判据**（可判定）：
  1. **确定性**：加载一个随仓库固定的小模型 ⇒ 顶点数 / 索引数 / 关节数**确定**；同一模型重复加载结果**逐值一致**；同一时刻采样的骨骼姿态**可复现**（两次采样逐位一致 + 对已知时刻断言具体矩阵值）。
  2. **失败即抛、不静默回退**：不存在的文件 / 非法字节流 ⇒ 抛 `std::runtime_error`（口径同 `texture_loader`）。
  3. **不在渲染帧加载**：加载是纯 CPU 路径（可从工作线程调用）；T68 不接线到主循环 ⇒ 无渲染帧开销。
  4. `ctest` 全绿 + 零警告 + 门禁 0 违规。
- **3A 基线三问**：
  1. **业界 / 3A 参照**：`Assimp` 官方 loader（glTF2 导入 + `aiScene`）；**UE5** 的 **Skeletal Mesh / Skeleton / AnimSequence 资源分离**（网格与动画分开存、运行时只采样）；**Unity** 的 `Mesh + SkinnedMeshRenderer + AnimationClip` 采样口径；**《原神》**的第三人称角色资源组织（网格 / 骨架 / 动画分包）。
  2. **本项目的 3A 基线形态（可判定）**：① **解析在加载期、运行期只做骨骼矩阵更新**（有耗时日志证据）；② 同一模型 / 同一动画时刻**逐值可复现**（单测钉住）；③ 公共头**不含 Assimp 类型**（分层硬约束，可静态检查）。
  3. **是否降级**：**无降级** —— 按 3A 形态做（T68 只到"加载 + 采样"，渲染是 T69 的范围，**不是降级**）。
- **测试夹具口径**：仓库内固定一个小型**蒙皮 glTF**（文本 `.gltf` + 内嵌 base64 缓冲，**进仓库**，非 `assets/models/` 的运行时资源）—— 含 **3 顶点 / 1 三角面 / 2 关节 / 1 条旋转动画**，足以覆盖"顶点 / 索引 / 关节数确定"与"给定时刻姿态可复现"。放在 `tests/fixtures/`（**不受 `.gitignore` 的 `assets/models/` 规则影响**）。

### 1.3 T69 施工细则（**2026-10-05 开工前补全**，符合 SKILL「任务下发」节）

- **模型裁定（所有者 2026-10-05 选定 = 候选 A）**：**Quaternius《Casual Female》**（由 **Cinevva** 分发）——
  **CC0**、**23 关节**、6,624 三角面、**单文件无外部贴图**、17 条动画含 **`Idle` / `Walk` / `Run` / `Jump`**；
  SHA-256 `3b4f39d27dc8a5f3b42d023f88a928679e7b1b0ea49ddb4857a07399bc4d8332`（取自 Cinevva 逐文件清单，**用作下载交叉校验**）。
  直链：`https://cdn.cinevva.com/assets/packs/quaternius/ultimate-animated-characters/Casual_Female.glb`
  **已知缺口**：**无独立 `Fall` 动画**（模型只有 `Jump`）⇒ 处置见 §1.4。
- **范围**：
  1. **资源**：`tools/fetch_assets.ps1` 增 `Kind = 'model'`（单文件 GLB → `assets/models/character/`）；`NOTICE.md` 台账 + `tools/assets.sha256` 同提交。
  2. **引擎**：**GPU 蒙皮渲染路径** —— 蒙皮顶点格式（position/normal/uv/joints/weights）、**骨骼矩阵走单次 storage buffer 上传**、蒙皮顶点着色器、`mesh_renderer` 新增 `UploadSkinnedMesh` 与每帧 `UpdateSkinningMatrices`。
  3. **游戏**：加载模型替换胶囊代理体；动画状态机 **`idle/run/jump/fall`**（**纯函数**，可单测）；**碰撞胶囊与手感不变**（半径 0.30 / 高 1.80 / 跳跃 1.08 格）。
  **明确不做（防蔓延）**：NPC 模型 / 动画混合树 / IK / 布料 / **根运动（root motion）** / **retarget（外部动画库）** —— 均不在 T69。
- **顺序**（每步可独立验证）：**S1 资源入库 → S2 引擎蒙皮渲染 → S3 游戏接线与状态机 → S4 验收**。
- **落点**：`tools/fetch_assets.ps1`、`NOTICE.md`、`tools/assets.sha256`、`assets/models/character/Casual_Female.glb`（**不入库**）、`engine/render/`（蒙皮网格渲染路径与着色器）、`assets/shaders/mesh_skinned.{vert,frag}`、`game/character_mesh.hpp`、`game/main.cpp`、`tests/`。
- **验收判据**（可判定）：
  1. **S1**：脚本幂等；模型文件 SHA-256 **等于**上记值；台账与 `assets.sha256` 齐全。
  2. **S2**：单测（骨骼矩阵打包 / 顶点打包为纯函数）+ 目视：**模型可见且姿态随动画变化**（不再是胶囊）。
  3. **S3**：单测（状态机：静止→`idle`、地面移动→`run`、起跳→`jump`、离地下降→`fall`）；目视：**脚底贴地无悬浮 / 无陷入**、**跑动无滑步**、相机不穿模（既有行为不回退）。
  4. **S4**：构建零警告 + `ctest` 全绿 + 门禁 0 违规 + **帧时间不劣化**（同基准档对比，无 > 50 ms 单帧）。
- **3A 基线三问**：
  1. **业界 / 3A 参照**：**UE5 Skeletal Mesh 的 GPU Skinning**（骨骼矩阵走 uniform / 常量缓冲，超限转 SRV / 纹理）；**Unity `SkinnedMeshRenderer` + GPU skinning**（`Mesh.SetBoneWeights` / `Mesh.bindposes`）；**《原神》**的角色资源分包（网格 / 骨架 / 动画分离）与状态机驱动。
  2. **本项目 3A 基线形态（可判定）**：① 蒙皮在**顶点着色器**完成，CPU 只算关节矩阵；② **每角色每帧 1 次**骨骼矩阵上传（storage buffer），**不逐物体推送**、不随世界总量增长（符合 SKILL 第四节）；③ 单角色关节数 ≤ 64（当前 **23**）⇒ 矩阵 ≈ 1.5 KB/角色/帧；④ 帧时间不劣化、无 > 50 ms 单帧。
  3. **是否降级**：**`fall` 的处置**依赖 §1.4 裁定（模型无 `Fall`）；**其余无降级**（按 3A 形态做）。
