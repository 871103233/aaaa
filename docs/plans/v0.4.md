### 1.3 W4 施工细则（2026-10-05 开工前补全，符合 SKILL「任务下发」节）

- **判据②口径修正（所有者 2026-10-05 裁定）**：原写"外观网格**水密**（`CountBoundaryEdges == 0`）"**对地表壳不可达**
  —— 依据：等值面网格只为 core cell 发射其**下侧**棱、区域 max 面的棱交给邻块（`volume_mesher.cpp` 四边形循环），
  而"地表壳"是**贴着地形、必然穿出任何有限区域的**开曲面 ⇒ 边界边恒 > 0（`== 0` 只在**闭合体**上成立）。
  修正为 **「无裂缝 + 内部无孔」**：以 **跨块共享面顶点逐位相同**（无裂缝）+ **退化三角形 = 0** 验证；
  `CountBoundaryEdges == 0` 留作 **W5 洞穴 / 有界闭合体**的判据。
- **范围**：地表壳的**表示 + 网格 + 近场渲染 + 碰撞接管**（一个**有界近场区域**；全图铺开属 W7 流式）。
  **明确不做（防蔓延）**：全图 / 流式（W7）；洞穴网络（W5）；水体（W6）；运行时破坏（休眠，W8）；
  精细悬垂造型（属内容，W5+）。
- **顺序**（每步可独立验证）：
  1. **S1 表示与网格**：`TerrainGenerationParams` 增 `[overhang]`（3D 噪声频率 / 幅度 / 通道）；`TerrainNoiseGenerator::OverhangAt(x,y,z)`；
     **新增** `world/shell/surface_shell.{hpp,cpp}` —— `SurfaceShellRegion` / `SurfaceShellParams` / `SurfaceShellSampler`（`IVolumeSampler`）/ `BuildShellBlockMesh`；密度 = `(y − 宏地表高度) + 悬垂噪声 × 幅度 × 边界淡出`。
  2. **S2 渲染 + 碰撞接管**：`game/main.cpp` —— 近场区域（**与可挖区域不重叠**，避免两套接管打架）内：
     组合四边形过滤器（resident ∪ shell）跳过地表四边形 → 该区域 tile 网格变空 → 既有的"空网格 ⇒ 交出高度场碰撞"路径**自动**生效；
     新增加载阶段：逐块网格化 → `UploadMesh`（渲染）+ `PhysicsWorld::AddMesh`（碰撞）；加入每帧绘制列表 + 视锥剔除。
  3. **S3 验收与文档**：单测（悬垂存在 / 确定性 / 无悬垂处贴合宏高度场 / **跨块共享面顶点逐位相同** / 退化 = 0）
     + 构建 / `ctest` / 门禁 + 运行冒烟 + 文档同步。
- **落点**：**新增** `world/shell/surface_shell.{hpp,cpp}`、`tests/surface_shell_test.cpp`；
  `world/generation/terrain_{params,noise}.{hpp,cpp}`、`assets/config/terrain.toml`、`world/CMakeLists.txt`、
  `tests/CMakeLists.txt`、`game/main.cpp`、`docs/engine-capabilities.md`、`docs/file-index.md`。
- **验收判据**（可判定）：
  1. **近场可见悬垂**：区域内存在"同一列有 ≥2 段实心"（表示级：竖直采样出现 ≥2 次符号变化）。
  2. **无裂缝 + 内部无孔**：相邻块在**共享面**上的顶点世界坐标**逐位相同**；网格**退化三角形 = 0**。
  3. **碰撞与外观同源**：同一块的网格同时用于渲染与 `Jolt MeshShape`（同一份 `MeshData`）。
  4. **与宏高度场无可见缝隙**：无悬垂处（悬垂幅度 → 0）等值面 y 与宏地表高度一致（容差 ≤ 1 格）；区域边界处悬垂**淡出到 0**。
  5. 构建零警告 + `ctest` 全绿 + 门禁 0 违规。
- **3A 基线三问**：
  1. **业界参照**：**Astroneer / No Man's Sky** 的 SDF 地表（近场体素、远处 LOD）；**Valheim** 的"高度场 + 局部洞穴体"；
     **UE5 Nanite/Landscape** 的"近场细节 + 远景简化"分层。
  2. **本项目 3A 基线形态（可判定）**：① 近场体积壳**与运行时同源**、确定性；② 无裂缝（跨块共享面顶点逐位相同）；

### 1.5 W5 施工细则（2026-10-06 开工前补全，符合 SKILL「任务下发」节）

- **范围**：在**地表壳的有符号距离场**上叠加**洞穴网络**（真三维隧道），并与地表**连通成可进入的出入口**；
  参数进 `assets/config/terrain.toml` 新增 `[caves]` 段；洞穴随壳**同一份网格** ⇒ 渲染 / 碰撞 / 层间接管零分叉。
  **明确不做（防蔓延）**：全图铺开 / 流式（W7）；水体（W6）；洞穴内容（矿脉 / 生物 / 光照）；运行时破坏（休眠，W8）；

- **顺序**（每步可独立验证）：
  1. **S1 参数与噪声**：`TerrainCaveParams`（`[caves]`：`enabled` / `frequency` / `tunnel_radius` /
     `carve_strength_blocks` / `depth_fade_blocks` / `seed_channel`）+ `TerrainNoiseGenerator::CaveCarveAt(x,y,z)`：
     两条**互不相关**的 3D 噪声 `a`、`b`，在 `sqrt(a²+b²) < tunnelRadius` 处返回雕刻量（格，`0 ~ carveStrengthBlocks`）。
  2. **S2 壳接入**：`SurfaceShellSampler::Sample` 的密度 = `(signedDistance + overhang + caveCarve × 边界淡出 × 深度淡出)`；
     **`caves.enabled == false` ⇒ `CaveCarveAt` 恒 0 ⇒ 与 W4 逐位一致**（既有测试不改）。
  3. **S3 验收与文档**：新增 `tests/cave_test.cpp`；构建 / `ctest` / 门禁 + 文档同步。
- **落点**：`world/generation/terrain_{params,noise}.{hpp,cpp}`、`world/shell/surface_shell.{hpp,cpp}`、
  `assets/config/terrain.toml`、`game/main.cpp`（启动日志）、**新增** `tests/cave_test.cpp`、`tests/CMakeLists.txt`、
  `docs/engine-capabilities.md`、`docs/file-index.md`、`docs/devlog.md`。
- **验收判据**（可判定）：

  - 做法：`ITerrainQuery` 增**带默认实现**的 `QueryObstructionWithRadius(from, to, radius, outSafeT)`（默认 = 调
    `QueryObstruction` ⇒ 退回无半径，既有实现与桩**不受影响**）；`GameCameraQuery` 覆盖为**半径感知步进**
    （沿线段每步检查中心 + **垂直于轴的 4 个环点**，任一实心即视为遮挡，返回最后一个安全比例）；
    `CameraSettings::cameraProbeRadius`（默认 0.25），`Evaluate` 改用它。固定步长 + 固定环方向 ⇒ 确定（红线 7）。
- **W6g 肩位偏移（over-the-shoulder）**
  - 做法：`CameraSettings::shoulderOffset`（默认 0，格；正 = 注视点朝**相机右方**偏移）；`PivotAt` 在插值后的注视点上
    叠加 `right(yaw) × shoulderOffset`（`right = (cos yaw, 0, −sin yaw)`，与 `forward` 正交）；`game/main.cpp` 设启用值。
    业界：半封闭空间用肩位偏移把角色移出画面中心，避免"镜头塌到身上"。
- **验收判据**：① `FollowTargetFadeOpacity` 开阔处 = 1、极近处 < 1 且**单调**；② 薄墙桩（覆盖 `QueryObstructionWithRadius`）
  下相机被拉近且不落在实心内；③ 肩位偏移后 `view.target` 沿相机右方平移该值，且 `normalize(eye − target)` **仍 = 悬臂方向**；
  ④ 构建零警告 + `ctest` 全绿 + 门禁 0 违规 + 冒烟无 ERROR（**含图形管线创建成功**）。
- **3A 基线三问**：① 参照 Unity Cinemachine `CinemachineDeoccluder`（`CameraRadius` 球投射 / `PullCameraForward`）、
  UE `USpringArmComponent`（probe 胶囊扫描）、TPS "贴脸 dither 淡出主角"、肩位偏移；② 本项目形态 = 相机半径
  `cameraProbeRadius`（0.25）+ 逐网格 `meshParams.x` 的片元 Bayer dither + `shoulderOffset`；
  ③ **是否降级**：无（三者均为新增能力；dither 淡出正是"看到人物内部"的正解）。
- **明确不做**：全屏后处理淡出；逐材质 alpha 混合（会引入排序问题）；**遮挡物**透明化（环境 dither，另立任务）。

### 1.11 W6h 施工细则（2026-10-06）：**避障阻尼 + 迟滞（治临界点抖动/闪烁）**

- **缺陷判定（契约 + 机制）**：
  - **契约**：相机朝向与距离的变化应当是**连续**的（无可见跳变）；临界点（遮挡刚好出现/消失）附近反复横跳**不得**导致画面闪烁。
  - **机制**：`Evaluate` 每帧按"当前这一帧的遮挡查询结果"**瞬时**决定跟随距离 —— 遮挡判定的结果在临界点是**布尔翻转**的
    （进/出各一次），于是距离在 `followDistance` 与"被拉近值"之间**瞬间跳变**；玩家在临界点往复 ⇒ 每帧翻转 ⇒
    ① 相机位置瞬移 **② 由 `view.distance` 驱动的**主角淡出不透明度**（W6e）跟着跳 ⇒ dither 图案跳变 ⇒ 画面闪烁**。
    （`safeT` 还是按步长量化的 ⇒ 还有 0.5 格级的台阶跳变。）
- **范围（业界口径）**：
  ① **推远阻尼**：遮挡消失后，跟随距离**按指数平滑推远**（帧率无关：`1 − exp(−dt/τ)`），并可用最大速度限幅 —— 对齐
  Cinemachine `CinemachineDeoccluder::Damping`（本仓库 `CameraSettings::avoidanceExtendDamping`，默认 0.25 s）。
  ② **迟滞（最短清晰时间）**：遮挡消失后须**持续** `avoidanceClearHold` 秒才允许开始推远 —— 对齐
  `MinimumOcclusionTime`（默认 0.2 s）。这正是"临界点横跳不闪"的关键。
  ③ **拉近立即**：**拉近不做阻尼**（安全优先：相机绝不允许留在墙里）—— 很多 TPS 亦如此（进快出慢的**非对称**阻尼）。
  ④ **状态归属**：平滑状态放在 `ThirdPersonCamera` 内，由**新增的** `UpdateAvoidance(frameDt, alpha, terrain)` **每渲染帧推进一次**；
  `Evaluate` 保持 `const`/幂等、只**读**该结果（红线 11：渲染求值绝不回写）—— 因为 `Evaluate` 每帧被调用**多次**（渲染 + 瞄准）。
  ⑤ **默认不启用平滑**：`m_avoidanceDistance < 0`（从未调用 `UpdateAvoidance`）时 `Evaluate` 退回**瞬时避障**旧路径 ⇒ 既有单测**逐值不变**。
  **明确不做**：把平滑放到固定逻辑步（遮挡查询依赖渲染侧地形查询接口）；对**朝向**做平滑（朝向必须紧跟输入，不做阻尼）。
- **落点**：`engine/render/camera.{hpp,cpp}`、`game/main.cpp`（持有状态 + 每帧推进）、`tests/render_camera_test.cpp`、
  `docs/engine-capabilities.md`、`docs/devlog.md`、`references/gameplay-v0.1.md`。
- **验收判据**（可判定）：
  1. **迟滞**：遮挡消失后 `avoidanceClearHold` 内距离**不变**（不立即回推）。
  2. **推远平滑**：超过迟滞后距离**逐渐**增大（单帧增量 < 全部差额），最终收敛到 `followDistance`。
  3. **拉近立即**：遮挡出现的那一帧距离**立即**等于目标（不留墙内）。
  4. **旧路径不变**：不调用 `UpdateAvoidance` 时，`Evaluate` 与既有行为**逐值一致**（既有 429 项全绿）。
  5. 构建零警告 + `ctest` 全绿 + 门禁 0 违规 + 冒烟无 ERROR。
- **3A 基线三问**：
  1. **业界参照**：Unity Cinemachine `CinemachineDeoccluder` 的 `Damping` / `DampingWhenOccluded` / `SmoothingTime` /
     `MinimumOcclusionTime`；UE5 `USpringArmComponent` 的 `CameraLag`（位移滞后）；通用做法 = **进快出慢的非对称阻尼 + 迟滞**。
  2. **本项目形态**：`avoidanceExtendDamping`（τ，0 = 立即）+ `avoidanceClearHold`（迟滞秒数）+ `avoidanceExtendMaxSpeed`
     （限速，0 = 不限）；拉近恒立即；状态经 `UpdateAvoidance` 每渲染帧推进一次。
  3. **是否降级**：**无降级**（新增平滑；拉近仍立即 ⇒ 安全性不降低；迟滞仅延后"回推"，不延后"拉近"）。
- **确定性说明**：平滑依赖**渲染帧 `dt`**，与既有 `alpha` 一样属**渲染侧表现**，不影响逻辑/世界确定性（红线 7 只约束世界数据）。

### 1.13 W7-S3b① 施工细则（2026-10-06）：**Ring 0 体积壳随玩家流式**

  2. **确定性**：同一入参两次调用 ⇒ 三个清单**逐值相同**（红线 7）；清单**升序**。
  3. **集合语义**：`toLoad = 目标 \ 常驻`、`toUnload = 常驻 \ 目标`；`toUnload` 不含仍在目标内的块。
  4. **重建语义**：`regionChanged == false` ⇒ `toRebuild` 为空；`regionChanged == true` ⇒ 目标内**最外圈**
     （`ceil(edgeFadeBlocks / 32)` 圈）的列块 ⊆ `toRebuild`。
  5. **常驻量只随窗口变化**：冒烟中壳块常驻量 = 窗口内目标块数（与世界总量无关）。
  6. 构建零警告 + `ctest` 全绿 + 门禁 0 违规 + 冒烟无 ERROR / WARN。
- **3A 基线三问**：
  1. **业界参照**：**UE5 World Partition**（HLOD / streaming levels：近场细节层随玩家流式加载）、
     **Horizon Zero Dawn streaming budget**（GDC 2015：load radius > active radius + 预算队列）、
     **Minecraft / Sodium** 的"区块近场细节层随窗口建卸"。
  2. **本项目 3A 基线形态（可判定）**：① 壳块常驻量 = 目标集 = **O(窗口)**，与 10 km 世界总量无关；
     ② 建 / 卸**分帧 + 有预算**，LOD / 壳块切换**不冻结画面**；③ `toRebuild` 显式登记（不静默丢几何）。
  3. **是否降级**：**无降级**。采**区域外圈重建**（而非"全局确定性淡出"）是本任务的设计选择（见上），
     已登记其代价；若日后判定重建量过大，按 ADR 0024「何时重新审视」处理（**不得**默默降级）。
- **世界内一致性**：
  - **真实世界**：壳块随离场**卸载**（碰撞体一并移除）⇒ 玩家走到哪都有真三维地表与碰撞；地表 tile 的碰撞
    在**接管翻转**时同步交还 / 收回 ⇒ 不会出现"看得见的壳没有碰撞"或"看不见的高度场挡路"。
  - **修仙世界**：无新增设定（壳属自然地貌，所有者口径"仿照现实世界的水和洞窟做即可"）。
