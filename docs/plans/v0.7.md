### 2.1 施工细则要点（H1 的硬约束）

- **旧逐网格路径不得删除**（SKILL §五「已实现能力只允许用配置项关闭」）：地表 tile / 动态网格 / 倒塌残骸继续走它；
  实例化走**新增路径**，由"是否实例化网格 + 实例数阈值"决定。
- **每帧一次上传**：实例变换打包进**常驻暂存缓冲** → 一次 copy pass；**禁止逐实例 push / 上传**（SKILL 硬规则 3）。
- **资源创建不得发生在渲染帧**：实例缓冲容量在创建时定死；管线随 MSAA 档位在 `SetMsaaSampleCount` 预建（照既有做法）。
- **超容量不静默**：实例数超出容量 ⇒ 截断 + **WARN**（含数量），并计入日志。
- **双格式 Shader**：两个新 vert 必须经 `glslc → SDL_shadercross` 产出 **SPIR-V + DXIL**（ADR 0002），否则另一种后端断言失败。
- **三层栈协同**：实例变换仍在**渲染相对坐标**下推送（红线 6：`网格原点 − 渲染原点` 在 `double` 下相减后落回 `float`）。

### 2.2 3A 基线三问（动手前三问）

1. **业界参照（点名）**：**UE5 ISM / HISM**（同 mesh+material 合批、per-instance transform 存 instance buffer）、
   **Unity GPU Instancing / `BatchRendererGroup`（DOTS）**、**Godot `MultiMesh`**；物理侧 **Jolt `Shape` 可被多 `Body` 共享**；
   远景 **UE5 HLOD proxy / Unity LOD Group**。
2. **本项目 3A 基线形态（可判定）**：① **draw call 与物件数解耦**（物件数 ×10 ⇒ draw call 增量 ≤ 类型数）；
   ② 仍满足 ADR 0024 的 **≤6000 次/帧** 与**密度阈值型**帧判据；③ **外观等价**（同相机 / 同场景一致，允许浮点级差）；
   ④ **阴影一致**（实例化物件仍投影、与主通道同源）。
3. **是否降级**：**有，且已确认**（所有者 2026-10-07）：**不做 impostor**（只到 LOD 链最粗一级）；
   **不做**合并式 HLOD 与 GPU-driven 剔除。切换条件写在 ADR 0034「何时需要重新审视」。

### 2.3 世界内一致性

- **真实世界**：实例化只改"怎么把同一份几何画很多次"，**不新增 / 不移动**任何物件 ⇒ 落点、贴地、碰撞**逐位不变**；
  物理**共享 Shape** 不改变碰撞外形（同几何同形状）；LOD 代理**只在远处**出现，近处几何不变。
- **修仙世界**：本阶段**不引入任何新设定 / 新内容**（纯引擎性能与规模化能力）⇒ 无需 `world-setting.md` 改动。
