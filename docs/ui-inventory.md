# 界面与交互清单（UI Inventory）

> **性质**：本仓库的**内容基线文档**之一（见 `.trae/skills/voxel-engine-dev-standards/SKILL.md` 第六节）。
> **回答的问题**：**游戏里有哪些界面、怎么打开、上面每个控件承诺做什么**。
> **维护义务**：任何**新增 / 修改 / 删除界面或控件**，必须**同一次提交内**更新本文件对应行；
> 未实现的界面**先占位**（状态 `未开始`），不得留白。

## 0. 最重要的两条规则

1. **控件标签即行为契约（affordance = contract）**
   一个控件写着什么，就**必须真的做那件事**："退出游戏"→ **真的退出进程**；"全屏"→ **真的切换显示模式**；
   "音量"→ **真的改变音量值并接到音频增益路径**。**禁止**放上"点了没反应""只是占位"的假控件。
2. **依赖缺失时必须显式标注，而不是做成假的**
   若控件的名义承诺依赖**尚未实现**的子系统（例：音量依赖音源与混音），处理方式是：
   **接通生效路径 + 在"当前限制"列写明"当前听不到效果 + 缺什么才能听到"**，
   并在回复中向项目所有者说明。**不允许**默默放一个无效滑块，也不允许为此顺手实现整个子系统（那属范围之外，须先登记需求）。

## 1. 状态图例

| 状态 | 含义 |
| --- | --- |
| **已实现** | 控件可交互且真的产生其承诺的效果 |
| **部分实现** | 可交互，但效果受未实现子系统限制（**必须在「当前限制」列说明**） |
| **未开始** | 界面或控件尚未实现 |
| **已移除** | 曾经存在后被删除（注明原因） |

## 2. 界面清单

### 2.1 系统面板（ESC 面板）

| 项 | 内容 |
| --- | --- |
| **位置** | 屏幕中央的模态面板（ImGui 窗口，居中显示于渲染输出之上） |
| **打开方式** | `Esc`（再次按 `Esc` 关闭） |
| **关闭方式** | `Esc`；关闭后**恢复打开前的鼠标捕获状态** |
| **与鼠标捕获的关系** | 打开时**释放**鼠标捕获（否则光标不可见、无法点控件）；关闭时恢复。与 T14 的捕获状态机统一，**`Esc` 不再单独承担"释放鼠标"职责** |
| **依赖** | ImGui 交互（须把 SDL 事件转发给 ImGui 后端）、`engine/platform/` 的显示模式与分辨率接口、设置持久化 |
| **状态** | **已实现**（2026-09-25） |

**控件清单**

| 控件 | 类型 | 名义承诺（必须实现的行为） | 状态 | 当前限制 |
| --- | --- | --- | --- | --- |
| 显示模式：窗口 | 二选一（单选） | 切到窗口模式，恢复窗口客户区尺寸 | **已实现** | — |
| 显示模式：全屏 | 二选一（单选） | 真的切到全屏（**桌面无边框全屏**） | **已实现** | — |
| 分辨率 | 下拉 / 列表（**仅窗口模式下可用**） | 真的把窗口客户区改为所选分辨率；全屏时置灰 | **已实现** | 档位取自 `SDL_GetFullscreenDisplayModes`，按尺寸去重升序 |
| 音量 | 0–100 拖动条 | 真的改变**主音量设置值**并写入**唯一增益入口** `ApplyMasterVolumeGain`；值持久化 | **部分实现** | **当前无音源与混音器 ⇒ 听不到效果**；要能听到还需：① `engine/audio/`（SDL3 音频流 + 混音器）② 在该入口把增益设到 master 总线 ③ 提供实际音源。**未初始化任何音频对象、未伪造声音** |
| 帧数上限 | 滑块 | **真的改变帧率上限**：范围 **60 ~ 当前显示器刷新率**，默认取刷新率；上限档 = 垂直同步（不空转），其余档 = 睡眠式限帧；值持久化 | **已实现** | 上限取决于**当前显示器**；换显示器或改刷新率后，启动时按新值**重新钳制**。睡眠档精度受 OS 调度粒度影响（Windows 约 1 ms），实测 FPS 会**略低于**目标——这是"零忙等、CPU 占用近零"的取舍 |
| 退出游戏 | 按钮 | **真的退出游戏进程**（保存设置 → 退出主循环 → 正常清理，退出码 0） | **已实现** | — |

> **可读性说明（T16 更新，2026-09-25）**：ImGui 内置默认字体**只有 ASCII 字形**，直接渲染中文会得到 `?`（**是缺字，不是乱码**）。
> **当前策略（已实现）**：启动时按**三级优先**解析 UI 字体 —— ① 仓库内 `assets/fonts/`（**默认不存在，静默跳过、不报错**）→
> ② 系统 CJK 字体（Windows `msyh.ttc` / `simhei.ttf` / `simsun.ttc`；Linux Noto CJK / 文泉驿；macOS PingFang）→ ③ 无 CJK 字体。
> **所有标签必须经唯一"标签缝"`game/ui_text.hpp` 取词**：解析到 CJK 字体 ⇒ 中文；否则 ⇒ **整表纯英文**。
> 因此**任何机器上都不会再出现缺字 `?`**；有单测遍历全部标签（回退时全为 ASCII）+ 扫描面板源码**禁止绕过标签缝**。
> 若要在所有平台统一中文，需内嵌 CJK 字体（`Noto Sans SC`，SIL OFL 1.1，子集化约 1–3 MB）到 `assets/fonts/`——**属新资产，须先登记**；当前默认不内嵌。

> **测试模式横幅的启动参数（T85）**：
> - `--auto-test` ⇒ 自动测试横幅（**请勿操作键盘 / 鼠标**）；`tools/vx_perf_input.ps1` 冒烟脚本自动传入。
> - `--manual-test="项1;项2;项3"` ⇒ 人工测试横幅并逐项列出（分号分隔；缺省显示通用提示"请按本次任务的验收项逐条确认"）。
>
> **W7 新增的两个测试开关（不改任何缺省行为；不属界面控件，登记在此以便复现）**：
> - `--map=<相对仓库根路径>` ⇒ 选择预设地图（缺省 `assets/maps/test_range.toml`）。用途：10 km 大世界（`assets/maps/world_10km.toml`）
>   与 1 km 手工测试场必须能共存（否则改默认地图就会让 W4~W6 的目视验收项失去场景）。
> - `--autofly=<秒>` ⇒ **确定性自动化飞行**（强制飞行 + 前进 + 上升，到时交还控制）。用途：给"10 km 飞越"提供
>   **可脚本化**的实测证据 —— 本机 / CI 抢不到前台窗口，`tools/vx_perf_input.ps1` 的按键注入到不了游戏（见该脚本的 focus guard）。
>   **只在带 `--auto-test` 时用于自动化取证**；缺省 0 = 完全不生效。
> - 参数经 `engine/platform/command_line.*` 以 **UTF-8** 取回（Windows 经 `GetCommandLineW` 还原，避免中文乱码）；启动日志同时打印模式与各项。

## 3. 设置项与持久化

| 设置 | 取值范围 | 默认 | 落盘位置 | 生效方式 |
| --- | --- | --- | --- | --- |
| 显示模式 | 窗口 / 全屏 | 窗口 | 见下 | 立即作用于窗口 |
| 分辨率 | 显示器支持的档位 | 启动时窗口尺寸 | 见下 | 立即作用于窗口（仅窗口模式） |
| 主音量 | 0–100 | 80 | 见下 | 立即写入设置并施加到音频增益路径（暂无音源） |
| 帧率上限 | **60 ~ 当前显示器刷新率** | 当前显示器刷新率 | 见下 | 立即生效；上限档走垂直同步，其余走睡眠式限帧 |
| 曝光（色调映射） | **0.1 ~ 8.0** | 1.0 | 见下 | **启动时读入**并作用于色调映射（ADR 0010 P0）。**当前无界面控件**（后续 P1 加光照参数时一并补 ESC 面板控件）；越界钳制、缺失取默认，**不需重编 Shader** |
| MSAA 档位 | **1 / 2 / 4 / 8**（1 = 关闭） | **2** | 见下 | **启动时读入**并作用于主通道的多采样目标（ADR 0010 P3）。越界取**最近的合法档（并列向上）**，缺失取默认；**档位 = 1 时不创建多采样纹理（零额外开销）**；若硬件不支持所选档，按能力降到不高于请求的最高受支持档。**当前无界面控件**（档位变化需重启生效）。**默认值 4 → 2 的依据（T66 / 2026-09-29 所有者裁定）**：地表换成真实 1024² PBR 贴图后纹理数组占 ≈ 85 MB，2560×1440 下 4× 要 154.69 MB、2× 只要 70.31 MB ⇒ **腾出的 84 MB 让总显存落在 ADR 0008 的 300 MB 内**（实测 ≈ 246 MB）；想改回 4× 需先解决显存超预算（用面板改档并重启即可试） |

**落盘**：设置保存为 TOML（复用 toml++，见 ADR 0005）。**实际路径 = `SDL_GetPrefPath("voxel-engine", "voxel_game")` + `settings.toml`**
（Windows 本机实测：`C:\Users\<用户>\AppData\Roaming\voxel-engine\voxel_game\settings.toml`）。
字段：`schema_version` / `display_mode`（`windowed` / `fullscreen`）/ `window_width` / `window_height` / `master_volume` / `frame_rate_cap` / `exposure` / `msaa_samples`。
**要求**：启动时读取并应用；文件缺失用默认值（**不报错**）；文件存在但非法（语法 / schema / 字段缺失或类型错 / 尺寸非正）则**明确报错**；数值越界则钳制。

## 4. 登记规则

1. **先登记后动手**：新增界面或控件前，先在第 2 节补行（状态 `未开始`），实现后回填状态与限制。
2. **每个控件必须写清四件事**：**类型** / **名义承诺（点了会发生什么）** / **状态** / **当前限制**。
3. **界面必须写清五件事**：**位置** / **打开方式** / **关闭方式** / **与鼠标捕获的关系** / **依赖**。
4. **技术选型去 ADR**：用什么 GUI 方案、如何持久化等若属选型，写在 ADR；本文件只写"有什么、点了会怎样"。
5. **需求去 `game-design.md`**：某个界面**为什么**要做，写在游戏设计的 G 编号里；本文件是它的落地清单。
